## 读取宠物选择偏好（getPetPreferences）

接口定义：`GET /api/v1/me/pet-preferences`。读取本人显式保存的当前宠物、默认宠物和偏好版本。

认证：移动端 Bearer 令牌。成功 HTTP 状态：`200`。

页面关联：`pet.picker`、`me.preferences`。

- 当前宠物供本次使用切换，默认宠物用于启动回退，两者分别保存。尚无偏好时字段为空、version=1。

### 传参 JSON 示例

```json
{}
```

本接口没有 JSON 请求体或业务参数；实际只发送认证等必要请求头。

### 传参字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `X-Request-ID` | 请求头 / string | 否 | 安全关联标识，最多 80 位字母、数字、点、下划线、连字符；非法或缺失时生成新值。 |
| `Authorization` | 请求头 / string | 是 | `Bearer <实际令牌>`；移动端 Bearer 令牌。 |

### 响应 JSON 示例

```json
{
  "code": "0",
  "message": "OK",
  "data": {
    "currentPetId": "22000000-0000-4000-8000-000000000001",
    "defaultPetId": "22000000-0000-4000-8000-000000000001",
    "version": 2
  },
  "requestId": "example-request-001"
}
```

示例使用虚构标识和凭证，表示一种成功状态；调用时以实际返回的 ID、版本、时间和令牌为准。

### 响应字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `code` | string | — | 稳定业务编码；成功为字符串 0，失败按 FAFA-* 分支。验证码字段例外，见请求用途。 |
| `message` | string | — | 可展示的安全提示；客户端不得解析消息文本判断业务状态。 |
| `data` | object | — | 本接口的业务数据；无返回数据或部分失败时为 null。 |

| `data.version` | integer | — | 正整数乐观锁版本；写入时提交最近读取的对应资源版本，冲突需重新读取。 |

## 查询本人额度申请（listMyQuotaRequests）

接口定义：`GET /api/v1/quota-grant-requests`。分页查询本人申请及审批结果。

认证：移动端 Bearer 令牌。成功 HTTP 状态：`200`。

页面关联：`me.usage`。

### 传参 JSON 示例

```json
{
  "query": {
    "limit": 20
  }
}
```

本接口没有 JSON 请求体。上方 `path`、`query` 仅解释路径和查询参数，实际按 URL 传递。

| 字段 | 类型 | 必填 | 说明 |

| `Authorization` | 请求头 / string | 是 | `Bearer <实际令牌>`；移动端 Bearer 令牌。 |

## 申请免费存储额度（requestFreeQuota）

认证：移动端 Bearer 令牌。成功 HTTP 状态：`201`。

页面关联：`me.grantRequest`。

- 申请不会立即增加可用额度。
