## 限制或恢复用户账号（setAdminUserStatus）

接口定义：`POST /api/admin/v1/users/{id}:set-status`。校验 USER_WRITE，经 RPC 修改账号状态及认证代际；管理操作意图先审计，业务和操作收据一起提交。

认证：管理员 Bearer 令牌。成功 HTTP 状态：`200`。

权限码：`USER_WRITE`。

页面关联：`admin.users`。

- ACTIVE 与 DISABLED 两种目标状态；恢复账号也不复活旧移动令牌。

### 传参 JSON 示例

```json
{
  "status": "DISABLED",
  "reason": "开发环境风控验收",
  "version": 2
}
```

### 传参字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `X-Request-ID` | 请求头 / string | 否 | 安全关联标识，最多 80 位字母、数字、点、下划线、连字符；非法或缺失时生成新值。 |
| `Authorization` | 请求头 / string | 是 | `Bearer <实际令牌>`；管理员 Bearer 令牌。 |
| `id` | path / string | 是 | 资源的稳定标识；按接口资源类型解释，不能作为授权凭据。 |
| `Idempotency-Key` | header / string | 是 | 幂等键，1—128 位字母、数字、点、下划线、冒号、连字符；网络重试复用原值，同键改内容返回 409。 |
| `status` | string | 是 | 账号目标状态，仅接受 ACTIVE、DISABLED。 最小长度 1。 |
| `reason` | string | 是 | 申请、审批或调整原因，非空，最多 500 字符。 最大长度 500；最小长度 0。 |
| `version` | integer | 是 | 正整数乐观锁版本；写入时提交最近读取的对应资源版本，冲突需重新读取。 |

### 响应 JSON 示例

```json
{
  "code": "0",
  "message": "OK",
  "data": {
    "id": "11000000-0000-4000-8000-000000000001",
```

## 直接赠送存储额度（grantAdminUserQuota）

接口定义：`POST /api/admin/v1/users/{id}/quota-adjustments`。校验 QUOTA_WRITE 后，经 RPC 向指定用户发放永久存储额度并写双方审计。

认证：管理员 Bearer 令牌。成功 HTTP 状态：`200`。

权限码：`QUOTA_WRITE`。

页面关联：`admin.quotaAdjustments`。

- entryType 仅接受 GRANT，amount 为正数；不支持直接改余额、负数冲正或支付。
- 网络结果未知时审计为 UNKNOWN；客户端保留原幂等键重试，不另开操作。

```json
{

  "amount": "1000",
  "entryType": "GRANT",
  "reason": "开发测试赠送"
}
```

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `X-Request-ID` | 请求头 / string | 否 | 安全关联标识，最多 80 位字母、数字、点、下划线、连字符；非法或缺失时生成新值。 |
| `Authorization` | 请求头 / string | 是 | `Bearer <实际令牌>`；管理员 Bearer 令牌。 |
| `id` | path / string | 是 | 资源的稳定标识；按接口资源类型解释，不能作为授权凭据。 |

## 审批存储额度申请（decideAdminQuotaRequest）

接口定义：`POST /api/admin/v1/quota-grant-requests/{id}:decide`。批准时在同一 Biz 事务中增加额度、写赠送流水并更新申请；拒绝时只记录审批决定。

认证：管理员 Bearer 令牌。成功 HTTP 状态：`200`。

权限码：`QUOTA_WRITE`。

页面关联：`admin.quotaRequests`。

- approved=true 时 amount 必填且为正整数字节串；false 时 amount 必须省略或为 null。
- 不同审批人再次处理已审批申请返回冲突；相同操作幂等重试返回首次结果，不重复赠送。

```json

  "amount": "1000",
```

## 管理员登录（createAdminSession）

接口定义：`POST /api/admin/v1/auth/sessions`。使用管理库中的独立账号登录；返回随机管理令牌，数据库仅保存令牌摘要。

认证：匿名。成功 HTTP 状态：`200`。

页面关联：`admin.login`。

- 示例账号并非系统预置账号；首次管理员必须通过初始化命令创建。
- 默认会话 3600 秒；默认每账号及直连 IP 在 900 秒窗口最多 10 次尝试。经同一 Gateway 的管理请求共享该入口 IP 限额。
- 管理令牌与移动端令牌完全隔离；角色权限在每次请求查询。

### 传参 JSON 示例

```json
{
  "username": "example-admin",
  "password": "ExampleAdminPassword123"
}
```

### 传参字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `X-Request-ID` | 请求头 / string | 否 | 安全关联标识，最多 80 位字母、数字、点、下划线、连字符；非法或缺失时生成新值。 |
| `username` | string | 是 | 管理员用户名，3—64 位，只允许字母、数字、点、下划线和连字符；区分大小写。 最小长度 1。 |
| `password` | string | 是 | 管理员密码，最长 128 字符；首次初始化要求 12—128 位且含字母和数字。 最大长度 128；最小长度 0。 |
