## 查询宠物头像引用（getPetAvatar）

接口定义：`GET /api/v1/pets/{id}/avatar`。返回头像媒体引用与宠物当前版本，未设置时 mediaId 为 null。

认证：移动端 Bearer 令牌。成功 HTTP 状态：`200`。

页面关联：`pet.detail`。

- 无 JSON 请求体；仅本人可读，删除等待期返回 404。实际预览需调用媒体访问凭证接口。

### 传参 JSON 示例

```json
{
  "path": {
    "id": "22000000-0000-4000-8000-000000000001"
  }
}
```

本接口没有 JSON 请求体。上方 `path`、`query` 仅解释路径和查询参数，实际按 URL 传递。

### 传参字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `X-Request-ID` | 请求头 / string | 否 | 安全关联标识，最多 80 位字母、数字、点、下划线、连字符；非法或缺失时生成新值。 |
| `Authorization` | 请求头 / string | 是 | `Bearer <实际令牌>`；移动端 Bearer 令牌。 |
| `id` | path / string | 是 | 资源的稳定标识；按接口资源类型解释，不能作为授权凭据。 |

### 响应 JSON 示例

```json
{
  "code": "0",
  "message": "OK",
  "data": {
    "petId": "22000000-0000-4000-8000-000000000001",
    "mediaId": "66000000-0000-4000-8000-000000000001",
    "version": 2
  },
  "requestId": "example-request-001"
}
```

示例使用虚构标识和凭证，表示一种成功状态；调用时以实际返回的 ID、版本、时间和令牌为准。

### 响应字段说明

| 字段 | 类型 | 必填 | 说明 |
|---|---|---|---|
| `code` | string | — | 稳定业务编码；成功为字符串 0，失败按 FAFA-* 分支。验证码字段例外，见请求用途。 |
| `message` | string | — | 可展示的安全提示；客户端不得解析消息文本判断业务状态。 |

## 绑定宠物头像（setPetAvatar）

接口定义：`PUT /api/v1/pets/{id}/avatar`。仅活动宠物可绑定同一主人、同一宠物范围内的 READY 图片；替换仅解除旧引用，不删除原素材。

认证：移动端 Bearer 令牌。成功 HTTP 状态：`200`。

页面关联：`pet.edit`。

- Idempotency-Key 必填；同键重放结果，旧版本返回 409；引用和宠物版本同事务提交。


## 创建图片上传会话（createUploadSession）

接口定义：`POST /api/v1/upload-sessions`。校验本人活动宠物，原子预占字节并创建持久化会话，不在幂等结果中保存签名凭证。

认证：移动端 Bearer 令牌。成功 HTTP 状态：`201`。

页面关联：`media.upload`、`pet.avatar`。

- v1 图片闭环仅支持 JPEG/PNG，默认最多 20 MiB、1600 万像素；同宠物主人可用。
- Idempotency-Key 必填；同键同内容重放创建回执，当前状态另查会话；不同内容返回 409。额度不足返回 409，超过大小上限返回 413。

## 核验并完成图片上传（completeUpload）

## 签发受限上传表单（createUploadPolicy）

接口定义：`POST /api/v1/upload-sessions/{id}/upload-policy`。为尚未过期的 INITIATED 会话签发同一期限的 POST 表单；不会延长原会话。

认证：移动端 Bearer 令牌。成功 HTTP 状态：`200`。

页面关联：`media.uploadQueue`。

- v1 图片闭环仅支持 JPEG/PNG，默认最多 20 MiB、1600 万像素；同宠物主人可用。

- 签名属于短期敏感信息，不写日志；重复请求允许重新签发，但不延长期限。配置缺失或存储故障返回 503。
