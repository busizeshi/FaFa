# 05 - 提醒系统

> 提醒系统帮助用户及时完成宠物日常护理和健康管理任务，包括驱虫、疫苗、剪指甲、洗澡等。

---

```
/pages/reminder/list    - 提醒列表
/pages/reminder/create  - 新建提醒
/pages/reminder/edit    - 编辑提醒
```

## 六、系统通知

### 6.1 微信订阅消息

**触发时机**：
- 提醒到期前 N 天（根据用户设置的提前提醒时间）
- 提醒到期当天
- 提醒逾期后每天

**消息内容**：
```
【FaFa 提醒】
宠物：豆包
提醒：体内驱虫
时间：今天应该完成
点击查看详情
```

**跳转路径**：
- 点击消息：跳转到提醒列表页面

---

### 6.2 订阅流程

**用户首次创建提醒时**：
1. 保存提醒成功后
2. 调用 `wx.requestSubscribeMessage`
3. 用户授权订阅消息
4. 订阅成功：显示「已开启提醒通知」
5. 订阅失败/拒绝：不影响提醒创建，只是不会收到推送

## 七、开发要点

### 7.1 数据请求

**提醒列表接口**：`GET /api/reminders`

**请求参数**：
```json
{
  "petId": "1",
  "status": "pending", // pending/completed/all
  "page": 1,
  "pageSize": 20
}
```

**返回数据**：
```json
{
  "code": 0,
  "data": {
    "reminders": [
      {
        "id": "1",
        "petId": "1",
        "type": "deworming",
        "title": "体内驱虫",
        "dueDate": "2026-08-21",
        "advanceNotice": 3,
        "repeat": "every_3_months",
        "status": "pending",
        "note": "使用拜宠清",
        "completedAt": null
      }
    ],
    "overdue": 1,
    "today": 2,
    "upcoming": 5
  }
}
```

---

**创建提醒接口**：`POST /api/reminders`

**请求数据**：
```json
{
  "petId": "1",
  "type": "deworming",
  "title": "体内驱虫",
  "dueDate": "2026-08-21",
  "advanceNotice": 3,
  "repeat": "every_3_months",
  "note": ""
}
```

---

**标记完成接口**：`POST /api/reminders/{id}/complete`

**请求数据**：
```json
{
  "completedAt": "2026-08-18 15:30",
  "note": "已经完成驱虫，使用了拜宠清",
  "photos": ["https://...", "https://..."]
}
```

---

### 7.2 本地存储

**提醒数据缓存**：
- Key：`reminders_${petId}`
- 有效期：10 分钟
- 刷新时机：创建/编辑/删除/完成提醒后清空缓存

**订阅消息状态**：
- Key：`subscribe_message_status`
- 值：`authorized` / `denied`
- 用于判断是否需要再次请求订阅

---

### 7.3 重复规则计算

**重复规则枚举**：
```javascript
const REPEAT_RULES = {
  none: '不重复',
  daily: '每天',
  weekly: '每周',
  bi_weekly: '每2周',
  monthly: '每月',
  quarterly: '每3个月',
  semi_annually: '每半年',
  annually: '每年',
  custom: '自定义'
};
```

**下次时间计算**：
```javascript
function calculateNextDate(currentDate, repeatRule) {
  switch (repeatRule) {
    case 'daily':
      return addDays(currentDate, 1);
    case 'weekly':
      return addWeeks(currentDate, 1);
    case 'bi_weekly':
      return addWeeks(currentDate, 2);
    case 'monthly':
      return addMonths(currentDate, 1);
    case 'quarterly':
      return addMonths(currentDate, 3);
    case 'semi_annually':
      return addMonths(currentDate, 6);
    case 'annually':
      return addYears(currentDate, 1);
  }
}
```

**AI 可以根据历史数据建议用户创建提醒**：

例如：

### 8.2 提醒完成率

**统计维度**：
- 本月提醒完成率
- 本年提醒完成率

**展示位置**：
- 报告中心（周报/月报）
- 宠物主页

**计算公式**：
```
完成率 = 已完成提醒数 / 总提醒数 × 100%
```
