# 04 - 成长档案

> 成长档案包括照片、日记、时间轴三个核心功能，记录宠物的成长瞬间和重要时刻。AI 照片搜索是本产品的重要差异化功能。

---

## 一、页面路径

```
/pages/pet/photos       - 照片列表
/pages/pet/photo-detail - 照片详情
/pages/pet/photo-search - AI 照片搜索
/pages/pet/diary        - 日记列表
/pages/pet/diary-detail - 日记详情
/pages/pet/diary-edit   - 新建/编辑日记
/pages/pet/timeline     - 时间轴
```

│  └────┘ └────┘ └────┘              │
│  相关度: ★★★★☆                      │  ← 相关度标识

│  2025年7月21日                       │
│  ┌────┐ ┌────┐                      │
│  │照片│ │照片│                      │

│                                     │

**排序方式**：
- 相关度（默认）：AI 匹配度从高到低
- 时间：从新到旧 / 从旧到新

- 5星：★★★★★（非常相关，score > 0.9）
- 4星：★★★★☆（相关，score > 0.7）
- 3星：★★★☆☆（一般，score > 0.5）

**AI 提示**：
- 如果搜索结果集中在某个时间段：显示提示
- 如果搜索词模糊：显示「你可能想找：[具体化的搜索词]」

### 10.2 性能优化

- 照片列表使用虚拟滚动
- 图片懒加载（lazy-load）
- 缩略图使用 CDN 裁剪（?x-oss-process=image/resize,w_400）
- 照片上传前压缩（最大 2MB）
- 搜索结果缓存（有效期 10 分钟）
