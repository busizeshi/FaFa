# 02 - 记录模块

> 记录模块是用户高频使用的功能，包括喂食、体重、饮水、排便、事件记录的列表和详情页面。设计原则：**记录一定不能麻烦，高频操作极简化**。

---

## 一、页面路径

```
/pages/record/index           - 记录模块入口（Tab Bar 第2个）
/pages/record/feeding/list    - 喂食记录列表
/pages/record/feeding/detail  - 喂食记录详情
/pages/record/weight/list     - 体重记录列表
/pages/record/weight/analysis - 体重分析（AI）
/pages/record/water/list      - 饮水记录列表
/pages/record/defecation/list - 排便记录列表
/pages/record/event/list      - 事件记录列表
/pages/record/event/detail    - 事件详情
```

## 十、开发要点

### 10.1 数据请求

**记录列表接口**：`GET /api/records/{type}`

**请求参数**：
```json
{
  "petId": "1",
  "type": "feeding", // feeding/weight/water/defecation/event
  "startDate": "2026-08-01",
  "endDate": "2026-08-18",
  "page": 1,
  "pageSize": 20
}
```

**返回数据**：
```json
{
  "code": 0,
  "data": {
    "records": [
      {
        "id": "1",
        "petId": "1",
        "type": "feeding",
        "time": "2026-08-18 15:30",
        "food": "皇家英短成猫粮",
        "amount": 32,
        "unit": "g",
        "note": "状态不错"
      }
    ],
    "total": 92,
    "stats": {
      "weekTotal": 28,
      "weekAverage": 73
    }
  }
}
```

### 10.2 性能优化

- 列表使用虚拟滚动（数据量大时）
- 下拉刷新 + 上拉加载更多
- 图表数据缓存（有效期 5 分钟）
- 左滑删除使用 CSS transform，避免重绘

### 10.3 埋点统计

- 查看记录列表：`view_record_list_{type}`
- 添加记录：`add_record_{type}`
- 编辑记录：`edit_record_{type}`
- 删除记录：`delete_record_{type}`
- 查看 AI 分析：`view_ai_analysis_{type}`
