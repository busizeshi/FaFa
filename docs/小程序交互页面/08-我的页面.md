### 3.2 设置项

#### 1. 通知设置

**提醒通知**：
- 开关控制是否接收提醒通知（微信订阅消息）
- 关闭后：不会再请求订阅消息授权

**报告通知**：
- 开关控制是否接收报告生成通知
- 关闭后：报告依然生成，但不推送通知

---

#### 2. 隐私设置

**允许 AI 分析数据**：
- 开关控制是否允许 AI 分析用户数据
- 关闭后：
  - AI 对话功能不可用
  - AI 照片搜索不可用
  - 不会生成 AI 发现和分析
  - 不影响数据记录和查看

## 七、开发要点

### 7.1 数据请求

**用户信息接口**：`GET /api/user/profile`

**返回数据**：
```json
{
  "code": 0,
  "data": {
    "user": {
      "id": "1",
      "nickname": "微信昵称",
      "avatar": "https://...",
      "recordDays": 127,
      "petCount": 3
    }
  }
}
```

---

**设置接口**：`POST /api/user/settings`

**请求数据**：
```json
{
  "reminderNotification": true,
  "reportNotification": true,
  "allowAiAnalysis": true
}
```

---

**意见反馈接口**：`POST /api/feedback`

**请求数据**：
```json
{
  "type": "feature",
  "content": "希望增加批量记录功能",
  "images": ["https://...", "https://..."],
  "contact": "13800138000"
}
```

---

**清除缓存**：
```javascript
// 清除图片缓存
wx.clearStorage()

// 清除文件缓存
wx.getFileSystemManager().removeSavedFile()
```

---

**导出数据接口**：`POST /api/user/export`

**请求数据**：
```json
{
  "types": ["records", "photos", "diaries", "reminders"],
  "format": "json"
}
```

**返回数据**：
```json
{
  "code": 0,
  "data": {
    "downloadUrl": "https://...",
    "expiresIn": 3600
  }
}
```

---

### 7.2 本地存储

**设置数据**：
- Key：`user_settings`
- 值：设置对象

**登录状态**：
- Key：`auth_token`
- 值：JWT Token

---

### 7.3 埋点统计

- 查看我的页面：`view_mine_page`
- 打开设置：`open_settings`
- 修改设置：`update_settings`
- 提交反馈：`submit_feedback`
- 查看关于：`view_about`
- 清除缓存：`clear_cache`
- 导出数据：`export_data`
- 退出登录：`logout`

## 八、产品细节

### 8.1 首次登录

**首次打开小程序**：
1. 显示引导页面（产品介绍 + Slogan）
2. 点击「开始使用」
3. 调用 `wx.login` 获取用户信息
4. 自动创建用户账号
5. 跳转到首页

---

### 8.2 数据安全

**数据存储**：
- 所有数据存储在服务器
- 本地仅缓存必要数据
- 照片使用 CDN 存储

**数据传输**：
- 全部使用 HTTPS
- 敏感数据加密传输

**数据导出**：
- 导出链接有效期 1 小时
- 仅用户本人可下载

---

### 8.3 账号注销

**未来功能（合规要求）**：
- 设置页面增加「注销账号」按钮
- 注销流程：
  1. 二次确认
  2. 告知注销后果（数据永久删除）
  3. 等待 7 天冷静期
  4. 正式注销
