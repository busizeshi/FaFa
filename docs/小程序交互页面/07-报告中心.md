# 07 - 报告中心

> 报告中心自动生成周报、月报，帮助用户了解宠物的生活状态和数据变化。核心价值：**让数据有温度，让记录有意义**。

---

## 一、页面路径

```
/pages/report/list      - 报告列表
/pages/report/weekly    - 周报详情
/pages/report/monthly   - 月报详情
```

### 2.2 报告卡片

**样式**：
```
圆角：12px
内边距：20px
左右外边距：16px
上下外边距：12px
```

**内容结构**：

1. **标题**
   - Icon：📊
   - 文字：「N月宠物月报」或「第N周周报」
   - 字号：18px
   - 字重：600

2. **时间范围**
   - 月报：「2026年8月」
   - 周报：「8月11日 - 8月17日」
   - 字号：14px

3. **数据概览（2x2 网格）**
   - 照片数：📷 N张
   - 日记数：📝 N篇
   - 喂食次数：🍚 N次
   - 体重状态：⚖️ 稳定/上升/下降
   - 字号：14px

4. **查看按钮**
   - 文字：「查看报告 →」
   - 字号：14px
   - 位置：右下角

**交互**：
- 点击卡片：跳转到报告详情页面
- 左滑：显示「删除」按钮

### 6.2 自动生成逻辑

**周报生成**：
- 时间：每周一 00:00
- 范围：上周一到上周日
- 触发方式：后端定时任务

**月报生成**：
- 时间：每月1号 00:00
- 范围：上个月1号到上个月最后一天
- 触发方式：后端定时任务

**生成条件**：
- 至少有 3 天有记录数据
- 至少有 1 条喂食记录
- 如果数据不足，跳过生成

---

### 6.3 性能优化

- 报告列表缓存（有效期 1 小时）
- 报告详情缓存（有效期 24 小时）
- 图表数据预计算（后端生成报告时计算）
- 海报生成异步处理（使用消息队列）

---

### 6.4 埋点统计

- 查看报告列表：`view_report_list`
- 查看周报：`view_weekly_report`
- 查看月报：`view_monthly_report`
- 生成自定义报告：`generate_custom_report`
- 分享报告：`share_report`
- 保存海报：`save_report_poster`
