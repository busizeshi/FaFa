# FaFa 宠物生活助手 - 小程序前端页面结构设计

> 版本：v1.0
> 依据文档：《产品功能设计.md》《数据库设计.md》
> 设计范围：P0 基础产品 + P1 第一批 AI 功能
> 说明：本文档只定义页面结构、内容、交互逻辑与数据交互，不涉及任何视觉风格、色彩方案、字体选择。

## 一、总体导航架构

### 1.1 底部 TabBar（4 个）

| Tab | 页面 | 核心定位 |
|-----|------|---------|
| 首页 | pages/index/index | 以"今天"为核心的操作中心：今日计划、今日提醒、快速记录、AI 发现、最近回忆 |
| 档案 | pages/archive/timeline | 宠物成长档案：时间轴聚合视图 + 照片/日记入口 |
| AI 助手 | pages/ai/index | AI 统一入口：动态推荐问题 + 历史会话 + AI 发现 |
| 我的 | pages/mine/index | 用户中心：宠物管理、提醒总览、报告、设置 |

### 1.2 全局机制

- **宠物切换器**：首页、档案、AI 助手顶部均展示当前宠物，点击弹出宠物切换浮层（横向滑动卡片列表 + "添加宠物"入口）。当前宠物 ID 全局缓存，所有记录类页面共享该上下文。
- **AI 分布式入口**：不设独立"AI 聊天 Tab"隔离区，AI 能力以"悬浮助手按钮 / 页面内 AI 卡片"形式分布于体重页、喂食页、照片页、报告页、时间轴页，统一跳转至 AI 对话页并携带上下文（pet_id + context_type + 预填问题）。
- **登录态**：全局 Token 拦截，未登录自动跳转登录页；微信静默登录（code2Session），无需用户手动操作。

### 1.3 页面层级总览

```
TabBar
├─ 首页(index) ──→ 快速记录弹层 / 各记录列表 / 提醒列表 / AI对话
├─ 档案(timeline) ──→ 时间轴 / 照片墙 / 日记 / 宠物档案主页 / 报告
├─ AI助手 ──→ AI对话页 / AI发现 / 照片搜索结果
└─ 我的 ──→ 宠物管理 / 提醒 / 报告 / 设置 / 反馈 / 关于

二级功能页
├─ 宠物模块：列表/创建/档案主页/编辑
├─ 记录模块：喂食/体重/饮水/排便/事件（各含 列表+创建编辑）
├─ 档案模块：照片墙/照片详情/照片上传/日记列表/日记编辑/日记详情
├─ 提醒模块：列表/创建编辑
├─ 报告模块：列表/详情
└─ 辅助：登录/设置/反馈/关于
```

## 三、页面内容规划

### P01 首页（今天）`pages/index/index`

**核心元素：**
1. **顶部宠物栏**：当前宠物头像、昵称、品种/性别/年龄摘要（如"英短 · 公 · 3岁2个月"）、当前体重、到家天数。点击切换宠物。
2. **今日计划/今日动态模块**：
   - 若已接受喂食计划：按时间顺序展示每餐（已完成 ✓ / 未完成 ○）
   - 若无计划：展示当日已发生的记录流（如"07:30 ✓ 早餐 25g"）
3. **今日提醒模块**：当日待办提醒列表（如"○ 剪指甲"），点击可直接标记完成。
4. **快速记录区**：6 个高频操作按钮——喂食、饮水、体重、排便、照片、事件。
5. **AI 发现卡片**：展示 1 条最新 AI 洞察（如"最近 14 天豆包体重基本稳定"），可左右切换，点击进入详情或 AI 对话。
6. **最近回忆卡片**："去年的今天，你上传了这张照片"，展示历史照片，点击进入照片详情。

**数据展示模块：** 今日喂食/饮水/体重/排便记录摘要（聚合接口）、当日到期提醒、最新未读 ai_discovery、历史同日照片。

**功能组件：** 宠物切换器、快速记录九宫格、快捷喂食弹层（见特殊交互）、提醒完成开关、AI 发现轮播、下拉刷新。

---

### P02 成长时间轴 `pages/archive/timeline`

**核心元素：**
1. **顶部宠物栏**（同首页，可切换）。
2. **月份分组时间轴**：按"2026年8月 → 8月17日"两级分组，每条聚合项带类型图标：
   - 📷 上传了 N 张照片（含首图缩略）
   - 📝 日记（含标题/首句）
   - 💊 完成驱虫/疫苗（来自提醒完成自动生成的事件）
   - ⚖️ 体重 5.2kg
   - 🍚 更换猫粮 / 日常事件
3. **筛选器**：按类型筛选（全部/照片/日记/事件/记录）。
4. **AI 入口**："生成本月回忆文案"按钮，跳转 AI 对话并携带时间轴上下文。

**数据展示模块：** 聚合各记录表 + photo + diary + event_record 按时间倒序分页流。

**功能组件：** 分组吸顶列表、类型筛选、无限滚动加载、单项点击跳对应详情。

---

### P03 AI 助手主页 `pages/ai/index`

**核心元素：**
1. **顶部引导语**："问问关于{宠物名}的任何事情"。
2. **动态推荐问题区**（非空输入框）：根据用户真实数据动态生成，例如：
   - "{宠物名}最近体重怎么样？"（存在体重记录时）
   - "这个月吃了多少猫粮？"（存在喂食记录时）
   - "帮我找去年夏天在阳台的照片"（存在带 AI 标签照片时）
   - "生成一份 8 月宠物月报"
3. **历史会话列表**：按 last_message_at 倒序，显示标题、最后消息预览、宠物标识，左滑归档/删除。
4. **AI 发现入口**：未读 ai_discovery 数量角标，点击进入 AI 发现列表。
5. **底部输入框**：直接开始新对话。

**功能组件：** 推荐问题动态生成逻辑、会话列表管理、新建会话。

---

### P04 我的 `pages/mine/index`

**核心元素：**
1. **用户信息区**：头像、昵称、宠物数量统计。
2. **功能入口列表**：
   - 我的宠物（宠物列表管理）
   - 提醒中心（全部提醒）
   - 宠物报告（周报/月报列表）
   - AI 发现
   - 设置（通知/AI 分析开关）
   - 意见反馈
   - 关于 FaFa

**数据展示模块：** user 基础信息、pet 数量、未读 ai_discovery 计数、待办提醒计数。

---

### P05 宠物列表 `pages/pet/list`

**核心元素：**
1. 宠物卡片列表（头像、昵称、品种、年龄、体重、状态标识：正常/已离世）。
2. **拖拽排序**：长按进入排序模式，调整 sort_order。
3. 底部"添加宠物"按钮。
4. 每张卡片操作：点击进入档案主页、编辑、删除（软删除，需二次确认）。

---

### P06 创建宠物 `pages/pet/create`

**核心元素（极简两步流程）：**
- **第一步（必填）**：昵称、种类（猫/狗/其他）、性别、出生日期、当前体重。
- **第二步（可选，可跳过）**：头像上传、品种、到家日期、是否绝育、毛色、备注。
- 顶部进度提示"几十秒完成建档"。

**业务约束**：出生日期不可晚于今天；体重范围校验（0.1~200kg）；宠物数量上限 max_pets_per_user（system_config）。

---

### P07 宠物档案主页（数字主页）`pages/pet/profile`

**核心元素：**
1. **档案头**：头像、昵称、"品种 · 性别 · 年龄"、当前体重、"来到你身边 N 天"。
2. **最近动态流**（最近 5 条，同时间轴格式）。
3. **AI 最近发现**："最近 30 天体重基本稳定" 等摘要卡片。
4. **数据概览格**：本月喂食次数 / 最新体重 / 照片数 / 日记数。
5. **记录快捷入口**：喂食/体重/饮水/排便/事件记录列表入口。
6. **档案操作**：编辑档案、生成报告、AI 问答。

**数据展示模块：** pet 详情 + 最近 30 天记录汇总（Python 汇总接口）+ 最新 ai_discovery + 时间轴首屏数据。

---

### P08 编辑宠物档案 `pages/pet/edit`

**核心元素：** 完整档案表单（P06 全部字段）+ 头像上传（OSS）+ 保存。校验规则同创建页。

---

### P09 喂食记录列表 `pages/record/feeding/index`

**核心元素：**
1. **日期分组列表**：按天分组，每条显示时间、食物名、品牌、数量+单位、类型标签（主粮/零食/罐头/其他）。
2. **快捷喂食按钮**：顶部常驻"一键喂食"（复制最近一次记录，见特殊交互）。
3. **日期范围筛选**：近 7 天/30 天/自定义。
4. **AI 分析入口**："分析最近一个月吃得是不是变少了"。
5. 每条记录：点击编辑、左滑删除。

---

### P10 喂食记录创建/编辑 `pages/record/feeding/edit`

**核心元素：**
1. **智能预填**：打开时自动填入"最近使用食品 + 上次喂食量 + 当前时间"（用户只需点保存，2~3 秒完成）。
2. 表单字段：喂食时间（时间选择器，默认当前）、食物名称（支持从历史食品快速选择）、食物类型（单选）、数量+单位（g/ml/罐/个）、品牌、备注。
3. 保存/删除（编辑态）。

---

### P11 体重记录与趋势 `pages/record/weight/index`

**核心元素：**
1. **趋势图表**：折线图展示体重变化，周期切换：7天/30天/3个月/半年/1年。
2. **趋势摘要条**：当前体重、最大、最小、趋势文字（上升/下降/稳定，来自后端趋势接口）。
3. **记录列表**：日期 + 体重 + 体况评分（BCS 1-9）+ 备注。
4. **AI 分析入口**："AI 分析最近体重变化"。
5. 同日重复记录提示（见特殊交互）。

---

### P12 体重记录创建/编辑 `pages/record/weight/edit`

**核心元素**：日期选择（默认今天）、体重数字键盘（支持 0.01 精度）、体况评分选择器（1-9 刻度，可选）、备注。
**业务规则**：同一天仅一条记录（uk_weight_pet_date 唯一索引）；保存成功后自动更新 pet.weight。

---

### P13 饮水记录列表 `pages/record/water/index`

**核心元素：** 日期分组列表（时间 + 饮水量 ml）、日期范围筛选、**日饮水统计卡**（当日总量/日均量对比）、新增按钮。

---

### P14 饮水记录创建 `pages/record/water/edit`

**核心元素**：饮水时间（默认当前）、饮水量（ml，数字键盘 + 常用量快捷键 50/100/150/200）、备注。

---

### P15 排便记录列表 `pages/record/excretion/index`

**核心元素：**
1. 类型筛选（全部/排便/排尿）、状态筛选（正常/偏软/偏硬/异常）。
2. 日期分组列表：时间、类型图标、状态标签、颜色描述、异常标记高亮。
3. **异常率统计卡**：近 30 天正常占比。
4. 点击记录可查看照片（如有）。

---

### P16 排便记录创建 `pages/record/excretion/edit`

**核心元素**：记录时间、类型（排尿/排便二选一）、状态（正常/偏软/腹泻/便秘/带血，仅排便类型显示）、颜色描述、照片上传（默认仅自己可见）、备注。

---

### P17 事件记录列表 `pages/record/event/index`

**核心元素**：
1. 事件类型筛选：洗澡/美容/就医/疫苗/驱虫/剪指甲/玩耍/其他。
2. 日期分组列表：时间、类型图标、标题、内容摘要、图片缩略图（最多 3 张）、地点/费用（如有）。
3. AI 自动标签展示（如"饮食变化""健康相关"）。

---

### P18 事件记录创建/编辑 `pages/record/event/edit`

**核心元素**：事件时间、事件类型（单选标签组）、标题、内容（多行文本）、标签（可多选）、地点、费用、图片上传（多张）、备注。

---

### P19 照片墙 `pages/archive/photo/index`

**核心元素：**
1. **瀑布流/时间分组网格**：按月分组，展示缩略图。
2. **AI 搜索框**："找一下去年夏天在阳台睡觉的照片"（自然语言搜索入口）。
3. **标签筛选**：AI 自动识别的标签（场景/行为/物品）。
4. 批量管理模式：多选删除、设置封面。

---

### P20 照片详情 `pages/archive/photo/detail`

**核心元素**：大图浏览（左右滑动切换）、拍摄时间、用户描述、AI 识别信息（场景/行为/物品/天气/时间）、AI 描述、相关标签、编辑描述/删除操作。

---

### P21 照片上传 `pages/archive/photo/upload`

**核心元素**：多选/拍照、批量上传进度、拍摄时间自动读取（EXIF）、批量描述填写、上传后提示"AI 正在识别照片内容"（异步：后台生成 ai_tags + embedding）。

---

### P22 日记列表 `pages/archive/diary/index`

**核心元素**：日期倒序列表（日期、标题、内容摘要、心情图标、天气、配图首图）、月份筛选、新建入口、AI 辅助写作入口。

---

### P23 日记创建/编辑 `pages/archive/diary/edit`

**核心元素**：日记日期、标题、正文（多行）、心情选择（开心/平静/担心/难过）、天气、配图、**AI 辅助开关**（开启后保存时标记 is_ai_assisted=1，并可一键生成初稿）。

---

### P24 日记详情 `pages/archive/diary/detail`

**核心元素**：完整正文、心情/天气元信息、图片画廊、编辑/删除操作、AI 入口（"根据这篇日记写一篇小红书"）。

---

### P25 提醒列表 `pages/reminder/index`

**核心元素：**
1. **双视图切换**：列表视图（按状态分组：待办/已完成/已过期）+ 日历视图（月历打点，某日提醒数）。
2. 提醒卡片：标题、类型图标、提醒时间、重复规则（每 3 个月等）、所属宠物。
3. **完成操作**：点击"已完成"→ 弹出确认（可附完成备注/照片）→ 自动生成事件记录 + 计算下一次时间。
4. 类型筛选：疫苗/驱虫/洗澡/剪指甲/体检/药物/生日/自定义。
5. 新建提醒按钮。

---

### P26 提醒创建/编辑 `pages/reminder/edit`

**核心元素**：
1. 关联宠物（默认当前宠物）、提醒标题、提醒类型（8 类单选）。
2. 提醒时间（日期+时间）。
3. **重复规则**：一次性/每天/每周（选周几）/每月（选几号）/每年/自定义（每 N 天、每 N 个月）。
4. 提前提醒（提前 N 分钟）。
5. 描述。

### 4.2 关键用户流程

**流程 A：每日喂食记录（目标 2~3 秒）**

**流程 B：周期提醒闭环（驱虫）**
```
P26 创建提醒（每 3 个月体内驱虫）
→ 到期首页/提醒列表高亮
→ 点"已完成" → 弹层（可附备注/照片）确认
→ 系统：① reminder 状态→completed，记录 completed_at
        ② 自动生成 event_record（type=deworming，标题"完成体内驱虫"）
        ③ 按 repeat_config 计算并生成下一次 pending 提醒
→ 时间轴自动出现"💊 完成本季度驱虫"
```

**流程 C：AI 数据问答（多轮上下文）**
```
P29 提问"豆包最近一个月体重怎么样？"
→ AI 调用 getWeightHistory → 流式返回分析
→ 用户问"饭量呢？"（继承：宠物=豆包，时间=最近一个月）
→ AI 调用 getFeedingHistory → 返回
→ 用户问"两者有没有关系？"
→ AI 调用两个工具 → 时间对齐 → 综合分析回答
```

**流程 D：AI 照片搜索**
```

→ 后端向量检索（Qdrant embedding）
→ P31 展示：统计 + AI 洞察摘要 + 按相关度排序照片网格
```

**流程 E：月报生成与查看**
```
P27 报告列表 → 点"生成 8 月月报"
→ 后端聚合当月全部记录 + AI 生成总结（report.content JSON）
→ 生成完成 → 进入 P28 详情
→ 可生成分享海报 / 复制文字（不代发布）
```

## 七、特殊交互说明

### 7.1 快捷喂食（核心体验，2~3 秒完成）

- 首页"喂食"按钮点击后**不直接进表单**，先弹出预填确认弹层：默认显示最近一次的"食品名 + 数量 + 当前时间"，用户直接点"保存"即完成。

- 成功 Toast 文案包含具体内容："已记录：皇家猫粮 30g"。

### 7.2 体重同日唯一性

- 数据库 `uk_weight_pet_date` 唯一索引兜底；前端提交前调后端校验。
- 冲突时提示并提供"去编辑当天记录"跳转按钮，避免用户重新输入。
- 保存成功后 pet.weight 联动更新，首页/档案页体重展示需同步刷新。

### 7.3 多宠物上下文切换

- 全局维护 currentPetId（Storage + 内存）；切换宠物后，首页/时间轴/各记录列表/AI 对话上下文全部切换。
- 记录创建页强制携带当前宠物 ID；AI 对话页允许临时切换宠物（仅影响当前会话 pet_id）。

### 7.4 提醒完成的级联动作（事务性）

- "已完成"操作在一个事务内完成：更新 reminder 状态 → 插入 event_record → 计算并插入下一条周期提醒。
- 支持附加完成备注与照片（completion_note / completion_images）。
- 若为"一次性"提醒则不生成下一次。

### 7.5 照片 AI 识别的异步状态

- 上传成功即返回，照片项显示"AI 识别中"占位状态。
- 后台识别完成回填 ai_tags/ai_description/embedding_id 后，列表刷新时状态自动变为可搜索。
- 未识别完成的照片不进入向量搜索结果（或降级为仅时间筛选）。

### 7.6 AI 对话流式输出与工具调用可视化

- AI 回复采用流式渲染；调用数据工具时展示过程提示（"正在查询体重记录…"），提升可信度。
- 数据类回答附带"数据卡片"（content_type=data，metadata 携带图表/表格数据），如体重趋势迷你折线。
- 多轮上下文继承：会话内自动继承宠物与时间范围，无需用户重复说明。

### 7.7 推荐问题动态生成（AI 主页）

- 非固定文案：根据 pet 数据存在性动态拼装（有体重记录才推"最近体重怎么样"），让用户首次进入即理解 AI 能力边界。

### 7.8 宠物拖拽排序

- 宠物列表长按进入排序模式，拖拽结束批量提交 sort_order；切换器展示顺序与列表一致。

### 7.9 照片默认私密

- 所有照片仅自己可见；排便照片等敏感内容不提供任何分享入口（产品原则）。
- 分享仅两条路径：报告分享海报（P28）、AI 生成文案复制（用户自行发布）。

### 7.10 时间轴自动生成

- 用户无需手工维护：任何记录/照片/日记/提醒完成产生的数据自动按时间进入时间轴。
- 同一天多条数据按时间倒序合并展示；"上传了 N 张照片"做聚合折叠。

### 7.11 边界与降级策略

- 无宠物：首页/档案页引导创建第一只宠物。
- 无记录：各列表页提供空态引导（插画+按钮直达对应创建页）；AI 推荐问题降级为基础功能介绍。
- allow_ai_analysis=0：隐藏 AI 发现/报告生成入口，AI 对话仅保留通用问答并提示。
- 网络异常：表单数据本地暂存（Storage），恢复后提示继续填写。
