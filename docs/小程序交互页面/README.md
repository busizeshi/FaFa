## 一、整体导航结构

### 1.1 Tab Bar（底部导航栏）

小程序采用标准的 4 Tab 结构：

```
┌─────────┬─────────┬─────────┬─────────┐
│  首页   │  记录   │  宠物   │  我的   │
│   🏠    │   📝    │   🐾    │   👤    │
└─────────┴─────────┴─────────┴─────────┘
```

**Tab 配置**：

| Tab | Icon | 标题 | 页面 | 说明 |
|-----|------|------|------|------|
| 1 | 🏠 | 首页 | `/pages/home/index` | 今日概览、快速记录入口 |
| 2 | 📝 | 记录 | `/pages/record/index` | 各类记录功能入口 |
| 3 | 🐾 | 宠物 | `/pages/pet/index` | 宠物档案、成长记忆 |
| 4 | 👤 | 我的 | `/pages/mine/index` | 个人设置、关于 |

**交互规则**：
- 选中态：Icon 和文字使用主题色 `#C4612F`（terracotta）
- 未选中态：使用灰色 `#999999`
- 点击 Tab 切换页面，无动画过渡

## 二、设计规范

### 2.1 色彩系统

**主色调（温暖大地色系）**

```css
/* 背景色 */
--bg-primary: #F7F4EF;      /* 温暖奶油色，页面主背景 */
--bg-surface: #FBF9F5;      /* 浅色表面，卡片背景 */
--bg-card: #FFFFFF;         /* 白色，卡片/弹窗背景 */

/* 边框色 */
--border-light: #E7E1D7;    /* 温暖发丝线 */

/* 文字色 */
--text-primary: #1F2421;    /* 深色主文字 */
--text-secondary: #5C635D;  /* 次要文字/说明文字 */
--text-placeholder: #999999; /* 占位符文字 */

/* 主题色 */
--color-primary: #C4612F;   /* 赤陶橙，主要按钮/强调色 */
--color-primary-hover: #A94E22; /* 按钮按下态 */
--color-primary-light: #F2E3D6; /* 浅色背景、标签 */

/* 功能色 */
--color-success: #52C41A;   /* 成功/完成 */
--color-warning: #FAAD14;   /* 警告 */
--color-error: #F5222D;     /* 错误/删除 */
--color-info: #1890FF;      /* 信息提示 */

/* 深色模式（暂不支持）*/
--bg-dark: #1F2421;         /* 温暖深色，预留 */
```

**使用规则**：
- 页面背景统一使用 `#F7F4EF`
- 卡片/列表项背景使用 `#FFFFFF`
- 主要操作按钮使用 `#C4612F`
- 次要按钮使用白底 + 边框
- 避免使用冷色调（蓝、紫、灰蓝）

---

### 2.2 字体系统

**字体家族**：

```css
/* 标题字体（衬线） */
font-family-heading: 'Playfair Display', 'DM Serif Display', serif;

/* 正文字体（无衬线）*/
font-family-body: 'Inter', -apple-system, BlinkMacSystemFont, 'Segoe UI', sans-serif;
```

**字号规范**：

| 用途 | 字号 | 字重 | 行高 | 场景示例 |
|------|------|------|------|----------|
| 大标题 | 32px | 600 | 44px | 页面主标题 |
| 中标题 | 24px | 600 | 32px | 卡片标题、区块标题 |
| 小标题 | 18px | 500 | 26px | 列表项标题 |
| 正文 | 16px | 400 | 24px | 正文内容 |
| 辅助文字 | 14px | 400 | 20px | 说明文字、时间 |
| 提示文字 | 12px | 400 | 18px | 表单提示、标签 |

**特殊样式**：
- 页面主标题使用衬线字体，其他使用 Inter
- 数字统一使用 tabular-nums（等宽数字）
- 标题中关键词使用斜体 + 主题色

---

### 2.3 间距系统

采用 8px 栅格系统：

```
--spacing-xs: 4px;    /* 极小间距，Icon 与文字 */
--spacing-sm: 8px;    /* 小间距，表单内元素 */
--spacing-md: 16px;   /* 中等间距，卡片内边距 */
--spacing-lg: 24px;   /* 大间距，区块间距 */
--spacing-xl: 32px;   /* 超大间距，页面顶部 */
```

**使用规则**：
- 页面左右边距：`16px`
- 卡片内边距：`16px`
- 卡片之间间距：`12px`
- 区块标题与内容间距：`12px`
- 表单字段间距：`16px`

---

### 2.4 圆角规范

```
--radius-sm: 8px;     /* 小圆角，按钮/输入框 */
--radius-md: 12px;    /* 中圆角，卡片 */
--radius-lg: 16px;    /* 大圆角，弹窗/模态框 */
--radius-full: 999px; /* 完全圆角，标签/Pill 按钮 */
```

---

### 2.5 阴影系统

```css
/* 卡片阴影（轻微） */
--shadow-card: 0 2px 8px rgba(0, 0, 0, 0.04);

/* 浮起阴影（悬停） */
--shadow-hover: 0 4px 12px rgba(0, 0, 0, 0.08);

/* 弹窗阴影 */
--shadow-modal: 0 8px 24px rgba(0, 0, 0, 0.12);
```

**使用场景**：
- 卡片默认使用 `shadow-card`
- 卡片按下/悬停使用 `shadow-hover`（Y 偏移增加 2-4px）
- 弹窗/底部菜单使用 `shadow-modal`

### 2.7 图标规范

**图标库**：使用 Ionicons 或自定义 SVG

**尺寸规范**：
- 小图标：16px（表单字段前缀）
- 中图标：24px（Tab Bar、列表项）
- 大图标：32px（功能入口）
- 超大图标：48px+（空状态）

**颜色规范**：
- 默认：`#5C635D`（次要文字色）
- 激活：`#C4612F`（主题色）
- 禁用：`#CCCCCC`

---

### 2.8 图片规范

**宠物头像**
- 尺寸：64x64px、80x80px、120x120px（不同场景）
- 圆角：50%（圆形）
- 占位图：灰色圆形 + Icon

**照片列表**
- 宽高比：1:1（正方形）
- 圆角：8px
- 间距：8px
- 每行：3 张

**照片详情**
- 全屏展示
- 支持左右滑动
- 背景：黑色 #000000

---

### 2.9 加载与状态

**加载动画**
- 使用系统原生 loading 组件
- 颜色：`#C4612F`

**骨架屏**
- 背景：`#F0F0F0`

**提示 Toast**
- 背景：`rgba(0, 0, 0, 0.8)`

## 三、AI 功能嵌入规范

根据产品设计原则，AI 不是独立页面，而是分布在各个功能中。以下是 AI 入口的统一规范：

### 3.1 AI 按钮样式

**浮动 AI 按钮（固定在页面右下角）**
```
尺寸：56x56px
背景色：渐变（#C4612F → #A94E22）
Icon：✨ 或 AI 图标，白色
圆角：50%（圆形）
阴影：0 4px 12px rgba(196, 97, 47, 0.3)
位置：距离右边 16px，距离底部 80px（避开 Tab Bar）

点击：打开 AI 对话面板（半屏弹窗）
```

**内嵌 AI 按钮（在功能区内）**
```
样式 1：Pill 按钮
  背景色：#F2E3D6
  文字色：#C4612F
  圆角：999px
  高度：32px
  Icon + 文字："✨ AI 分析"

样式 2：卡片按钮
  背景色：渐变（#F2E3D6 → #FFFFFF）
  边框：1px solid #C4612F（虚线）
  圆角：12px
  内边距：16px
  Icon + 标题 + 描述
```

---

### 3.2 AI 对话面板

**展现形式**：半屏弹窗（从底部弹出，高度 60vh）

**结构**：
```
┌────────────────────────────────┐
│  [关闭]      AI 助手      [清空] │  ← 顶部标题栏（56px）
├────────────────────────────────┤
│                                │
│   对话内容区（滚动）             │  ← 对话气泡
│                                │
│   用户消息：右侧，浅蓝背景       │
│   AI 回复：左侧，白色背景        │
│                                │
├────────────────────────────────┤
│  [输入框]            [发送按钮] │  ← 底部输入栏（固定）
└────────────────────────────────┘
```

**交互规则**：
- 点击空白区域不关闭（用户可能正在阅读）
- 点击顶部"关闭"按钮关闭
- 发送消息后自动滚动到最新消息
- 支持长按消息复制内容

---

### 3.3 AI 功能建议词

在无历史对话时，展示建议问题：

```
快速开始：

📊 豆包最近体重怎么样？

📷 帮我找去年夏天在阳台的照片
```

建议词根据当前页面上下文动态生成：

## 五、开发注意事项

### 5.1 微信小程序兼容性

- 使用 `rpx` 作为尺寸单位（750rpx = 屏幕宽度）
- 本文档中的 `px` 需转换为 `rpx`：1px = 2rpx（iPhone 6 基准）
- 避免使用微信小程序不支持的 CSS 属性（如 `backdrop-filter`）
- 图片使用 `<image>` 标签，设置 `mode="aspectFill"`

### 5.2 性能优化

- 列表使用虚拟滚动（`<scroll-view>`）
- 图片懒加载（`lazy-load="true"`）
- 避免频繁 `setData`，合并数据更新
- 大图压缩后上传，缩略图使用 CDN 裁剪

### 5.3 数据mock

开发阶段可使用以下 Mock 数据：

```javascript
// 宠物数据
const mockPet = {
  id: '1',
  name: '豆包',
  avatar: '/images/pet-avatar.jpg',
  species: 'cat',
  breed: '英短',
  gender: 'male',
  birthDate: '2023-06-01',
  weight: 5.2,
  age: '3岁2个月'
};

// 记录数据
const mockFeeding = {
```
