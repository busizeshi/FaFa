# 01 - 首页交互设计

> 首页是用户每天打开小程序后的第一个页面，核心定位是「今日概览 + 快速记录」，帮助用户快速了解宠物今日状态并完成高频记录操作。

---

## 一、页面路径

```
/pages/home/index
```

**Tab Bar 位置**：第 1 个 Tab（🏠 首页）

---

## 三、详细设计

### 3.1 顶部宠物选择器

**位置**：页面顶部，固定

**样式**：
```
高度：64px
左右内边距：16px
```

**内容结构**：
```
┌──────────────────────────────────┐
│  [头像] 豆包  ▼     [+ 新建宠物]  │
└──────────────────────────────────┘
```

**元素说明**：

1. **宠物头像**
   - 尺寸：40x40px
   - 圆角：50%（圆形）
   - 左侧 Icon（16px）：代表宠物种类（🐱/🐶）

2. **宠物名称 + 下拉箭头**
   - 字号：18px
   - 字重：500
   - 箭头：12px

3. **新建宠物按钮**
   - 右侧对齐
   - 文字按钮：`+ 新建宠物`
   - 字号：14px

**交互行为**：

- **点击宠物名称区域**：弹出宠物切换底部菜单
  ```
  ┌────────────────────────────┐
  │     切换宠物               │  ← 标题
  ├────────────────────────────┤
  │  🐱 豆包（当前）            │  ← 已选中
  │  🐶 团子                    │
  │  🐱 小花                    │
  ├────────────────────────────┤
  │  + 新建宠物                 │  ← 操作项
  └────────────────────────────┘
  ```
  - 点击某个宠物：切换首页数据，关闭菜单
  - 当前宠物有特殊标识（对勾图标）

- **点击新建宠物**：跳转到 `/pages/pet/create`（新建宠物页面）

**状态**：
- 如果用户还没有宠物：显示「+ 创建第一只宠物」按钮，点击跳转

## 四、快速记录弹窗详细设计

用户点击快速记录按钮后，从底部弹出对应的记录表单。

### 4.1 喂食记录弹窗

**样式**：
```
弹窗类型：Action Sheet（底部弹出）
圆角：16px 16px 0 0
最大高度：70vh
内边距：16px
```

**内容结构**：
```
┌────────────────────────────────────┐
│  记录喂食               [关闭 ✕]    │  ← 标题栏
├────────────────────────────────────┤
│                                    │
│  时间                               │
│  [2026-08-18 15:30]  [现在]       │  ← 时间选择
│                                    │
│  食物                               │
│  [皇家英短成猫粮      ▼]           │  ← 下拉选择
│                                    │
│  数量                               │
│  [30]  g                           │  ← 数字输入
│                                    │
│  备注（可选）                       │
│  [                              ]  │  ← 文本输入
│                                    │
│             [保存]                 │  ← 主要按钮
└────────────────────────────────────┘
```

**字段说明**：

1. **时间**
   - 默认值：当前时间
   - 右侧「现在」按钮：快速设置为当前时间
   - 点击时间：打开时间选择器（系统原生）

2. **食物**
   - 下拉选择（显示最近使用的食物）
   - 如果用户有食品库：从食品库选择
   - 如果没有：输入文本
   - 点击后弹出食物选择器：
     ```
     ┌──────────────────┐
     │  皇家英短成猫粮   │  ← 最近使用
     │  冻干鸡肉        │
     │  + 添加新食物     │  ← 操作项
     └──────────────────┘
     ```

3. **数量**
   - 数字输入框
   - 默认值：上次喂食量
   - 单位：g（固定）
   - 支持小数（保留 1 位）

4. **备注**
   - 文本输入框
   - 可选字段
   - 占位符：「补充说明（可选）」

**交互行为**：
- **点击保存**：
  1. 验证必填字段
  2. 提交数据到后端
  3. 显示 Toast「记录成功」
  4. 关闭弹窗
  5. 刷新首页数据（今日计划更新）

- **点击关闭**：
  - 如果表单有改动：二次确认「放弃本次记录？」
  - 如果表单无改动：直接关闭

**验证规则**：
- 时间：必填
- 食物：必填
- 数量：必填，大于 0
