## 五、AI 对话上下文管理

### 5.1 会话管理

**会话创建**：
- 用户每次打开对话面板：创建或恢复会话
- 会话 ID 存储在本地（localStorage）
- 会话有效期：7 天

**上下文保持**：
- 同一会话内，AI 可以理解前后文
- 例如：
  ```
  用户: 豆包最近体重怎么样？
  AI: 最近30天体重从5.3kg降至5.0kg...
  
  用户: 饭量呢？
  AI: (理解用户在问豆包的饭量) 最近30天平均每日喂食73g...
  
  用户: 两者有没有关系？
  AI: (理解体重和饭量的关系) 结合数据来看...
  ```

**会话清空**：
- 用户点击「清空」按钮：清空当前会话
- 超过 7 天未使用：自动清空

---

### 5.2 数据权限

**AI 可访问的数据**：
- 当前选中宠物的所有数据
- 用户主动上传的照片、日记
- 系统记录的数据（喂食、体重等）

**AI 不可访问的数据**：
- 其他用户的数据
- 其他宠物的数据（除非用户明确指定）

## 六、开发要点

### 6.1 数据请求

**AI 对话接口**：`POST /api/ai/chat`

**请求数据**：
```json
{
  "sessionId": "session_123",
  "petId": "1",
  "message": "豆包最近体重怎么样？",
  "context": {
    "previousMessages": [
      {"role": "user", "content": "..."},
      {"role": "assistant", "content": "..."}
    ]
  }
}
```

**返回数据**：
```json
{
  "code": 0,
  "data": {
    "reply": "根据最近30天的体重记录，豆包的体重从5.3kg降至5.0kg，下降约5.7%...",
    "actions": [
      {
        "type": "button",
        "text": "查看详细分析",
        "url": "/pages/record/weight/analysis"
      }
    ],
    "data": {
      "type": "chart",
      "chartData": {...}
    }
  }
}
```

## 七、AI 能力总结

| 能力 | 说明 | 实现方式 | 页面入口 |
|------|------|----------|----------|
| **数据查询** | 查询宠物历史数据 | Agent 调用工具 | 各数据页面 |
| **数据分析** | 分析数据趋势和变化 | Agent + LLM 总结 | 体重/喂食页面 |
| **照片搜索** | 自然语言搜索照片 | 向量搜索 + LLM | 照片列表 |
| **内容创作** | 生成小红书/抖音文案 | LLM 生成 | AI 助手主页 |
| **报告生成** | 生成周报/月报 | 数据聚合 + LLM | 报告中心 |
| **智能建议** | 喂食计划、健康建议 | 规则 + LLM | 宠物主页 |
| **趋势发现** | 主动发现异常趋势 | 定时分析 | 首页/宠物主页 |
| **日记辅助** | 根据照片生成日记 | 图片理解 + LLM | 日记编辑 |
