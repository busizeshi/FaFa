## 配置文件说明

| 文件 | 说明 | 用途 |

```
fafa-java/src/main/resources/
```

## 快速开始

### 1. 复制配置文件

```bash
# 项目根目录
cd D:\dev\Java\FaFa
cp .env.example .env

# Python 服务
cd fafa-python
cp .env.example .env
```

### 2. 配置数据库

**方式一：使用本地 Docker 中间件**

确保已按照 `docs/deploy/README.md` 启动了所有中间件服务。

`.env` 文件配置：
```ini
MYSQL_HOST=localhost
MYSQL_PORT=3306
MYSQL_DATABASE=fafa
MYSQL_USERNAME=fafa
MYSQL_PASSWORD=fafa_123456
```

**方式二：使用远程中间件**

如果使用服务器上的中间件，修改 `.env`：
```ini
MYSQL_HOST=your_server_ip
MYSQL_PORT=3306
MYSQL_DATABASE=fafa
MYSQL_USERNAME=fafa
MYSQL_PASSWORD=your_password
```

### 3. 初始化数据库

**创建数据库**:
```sql
CREATE DATABASE IF NOT EXISTS fafa DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

CREATE USER 'fafa'@'%' IDENTIFIED BY 'fafa_123456';
GRANT ALL PRIVILEGES ON fafa.* TO 'fafa'@'%';
FLUSH PRIVILEGES;
```

**导入表结构**:
```bash
# 连接数据库
mysql -h localhost -u fafa -p fafa

# 执行数据库设计文档中的建表 SQL
# 或使用 Flyway/Liquibase 进行版本管理
```

### 4. 配置必需的 API Key

#### 通义千问 API Key

1. 访问 [DashScope 控制台](https://dashscope.console.aliyun.com/)
2. 创建 API Key
3. 修改 `.env` 和 `fafa-python/.env`：
   ```ini
   DASHSCOPE_API_KEY=sk-xxxxxxxxxxxxxxxx
   ```

#### 微信小程序配置

1. 访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 获取 AppID 和 AppSecret
3. 修改 `.env`：
   ```ini
   WECHAT_APPID=wx1234567890abcdef
   WECHAT_SECRET=abcdef1234567890abcdef1234567890
   ```

### 5. 启动服务

**启动 Java 服务**:
```bash
cd fafa-java
mvn spring-boot:run -Dspring-boot.run.profiles=dev
```

**启动 Python 服务**:
```bash
cd fafa-python
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
```

## 详细配置说明

### MySQL 配置

| 配置项 | 开发环境 | 生产环境 | 说明 |
|--------|---------|---------|------|
| `MYSQL_HOST` | localhost | 服务器IP | 数据库地址 |
| `MYSQL_PORT` | 3306 | 3306 | 数据库端口 |
| `MYSQL_DATABASE` | fafa | fafa | 数据库名称 |
| `MYSQL_USERNAME` | fafa | fafa | 数据库用户名 |
| `MYSQL_PASSWORD` | fafa_123456 | 强密码 | 数据库密码 |

**连接池配置** (Java):
```yaml
hikari:
  maximum-pool-size: 10      # 最大连接数
  minimum-idle: 5            # 最小空闲连接
  connection-timeout: 30000  # 连接超时(ms)
  idle-timeout: 600000       # 空闲超时(ms)
  max-lifetime: 1800000      # 最大生命周期(ms)
```

---

### Redis 配置

| 配置项 | 开发环境 | 生产环境 | 说明 |
|--------|---------|---------|------|
| `REDIS_HOST` | localhost | 服务器IP | Redis 地址 |
| `REDIS_PORT` | 6379 | 6379 | Redis 端口 |
| `REDIS_PASSWORD` | (空) | 强密码 | Redis 密码 |
| `REDIS_DB` | 0 (Java) / 2 (Python) | 同左 | 数据库编号 |

**用途**:
- Java: Session 缓存、分布式锁、缓存数据
- Python: AI 对话缓存、照片分析结果缓存

---

### RocketMQ 配置

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `ROCKETMQ_HOST` | localhost | NameServer 地址 |
| `ROCKETMQ_PORT` | 9876 | NameServer 端口 |

**Topics**:
- `photo-analysis`: 照片 AI 分析任务
- `report-generation`: 报告生成任务

**Consumer Groups**:
- `fafa-producer-group`: Java 生产者组
- `fafa-photo-consumer`: Python 照片分析消费者
- `fafa-report-consumer`: Python 报告生成消费者

---

### MinIO 配置

| 配置项 | 开发环境 | 生产环境 | 说明 |
|--------|---------|---------|------|
| `MINIO_ENDPOINT` | http://localhost:9000 | http://服务器IP:9000 | MinIO 地址 |
| `MINIO_ACCESS_KEY` | minioadmin | 自定义 | Access Key |
| `MINIO_SECRET_KEY` | minioadmin123 | 强密码 | Secret Key |
| `MINIO_BUCKET` | fafa | fafa | 存储桶名称 |

**存储内容**:
- 宠物头像
- 宠物照片（原图 + 缩略图）
- 事件图片
- 报告封面

**访问控制台**: http://localhost:9001

---

### Qdrant 向量数据库

| 配置项 | 值 | 说明 |
|--------|-----|------|
| `QDRANT_HOST` | localhost | Qdrant 地址 |
| `QDRANT_PORT` | 6333 | HTTP API 端口 |
| `QDRANT_GRPC_PORT` | 6334 | gRPC 端口 |
| `QDRANT_COLLECTION_NAME` | fafa_photos | Collection 名称 |

**用途**: 存储照片的向量 Embedding，实现语义搜索

**向量维度**: 1536 (text-embedding-v2)

**访问控制台**: http://localhost:6333/dashboard

```ini

LOG_LEVEL=DEBUG

```

## 常见问题

### Q1: 数据库连接失败

**错误信息**: `Communications link failure`

**解决方案**:
1. 检查 MySQL 是否启动
   ```bash
   docker ps | grep mysql
   ```
2. 检查端口是否开放
   ```bash
   netstat -an | findstr 3306
   ```
3. 检查用户名密码是否正确
4. 检查防火墙规则

---

### Q2: Redis 连接失败

**错误信息**: `Could not connect to Redis`

**解决方案**:
1. 检查 Redis 是否启动
   ```bash
   docker ps | grep redis
   ```
2. 测试连接
   ```bash
   redis-cli -h localhost -p 6379 ping
   ```
3. 如果设置了密码，添加到配置文件

---

### Q3: MinIO 上传失败

**错误信息**: `Access Denied`

**解决方案**:
1. 检查 Access Key 和 Secret Key 是否正确
2. 检查 Bucket 是否已创建
3. 在 MinIO 控制台创建 Bucket:
   - 访问 http://localhost:9001
   - 登录后创建名为 `fafa` 的 Bucket
   - 设置访问策略为 `public`（可选）

---

### Q4: Qdrant 连接失败

**错误信息**: `Connection refused`

**解决方案**:
1. 检查 Qdrant 是否启动
   ```bash
   docker ps | grep qdrant
   ```
2. 访问控制台测试: http://localhost:6333/dashboard
3. 检查 Collection 是否已创建（首次启动会自动创建）

---

### Q5: RocketMQ 消息发送失败

**错误信息**: `No route info`

**解决方案**:
1. 检查 NameServer 和 Broker 是否都在运行
   ```bash
   docker ps | grep rocketmq
   ```
2. 检查 Topic 是否已创建
3. 访问 RocketMQ Dashboard: http://localhost:8080
4. 手动创建 Topic: `photo-analysis`, `report-generation`

---

### Q6: 通义千问 API 调用失败

**错误信息**: `Invalid API Key` 或 `Rate limit exceeded`

**解决方案**:
1. 检查 API Key 是否正确
2. 检查账户余额是否充足
3. 检查 API 调用频率是否超限
4. 访问控制台查看详细错误: https://dashscope.console.aliyun.com/

## 安全建议

### 开发环境

- ✅ 使用简单密码方便调试
- ✅ 可以关闭 SSL
- ✅ 打开详细日志

### 生产环境

- ⚠️ **必须使用强密码**
- ⚠️ **开启 SSL/TLS**
- ⚠️ **配置防火墙规则**
- ⚠️ **定期备份数据**
- ⚠️ **关闭不必要的端口**
- ⚠️ **使用环境变量而非硬编码**
- ⚠️ **定期更新中间件版本**
