# FaFa 宠物生活助手 - 接口文档

## 基础说明

### 接口地址
- **开发环境**: `http://localhost:8080/api`
- **生产环境**: `https://api.fafa.com/api`

### 通用响应格式

所有接口均返回统一格式：

```json
{
  "code": 200,
  "message": "success",
  "data": {},
  "timestamp": 1692345678901
}
```

**响应码说明**：
- `200`: 成功
- `400`: 业务异常（客户端错误）
- `401`: 未授权
- `403`: 禁止访问
- `500`: 服务器错误

### 认证说明

需要登录的接口，请在请求头中携带 Token：

```
Authorization: your_token_here
```

## 一、用户认证模块

### 1.1 微信小程序登录

**接口定义**: 使用微信 code 登录，获取用户信息和访问令牌

**接口地址**: `POST /auth/wechat/login`

**是否需要认证**: 否

**请求参数**:

```json
{
  "code": "081Xva1w3Lfs9P2AZq3w3a6a0I0Xva1F"
}
```

**参数说明**:

| 参数名 | 类型 | 必填 | 说明 |
|--------|------|------|------|
| code | String | 是 | 微信登录凭证，通过 wx.login() 获取 |

**响应示例**:

```json
{
  "code": 200,
  "message": "success",
  "data": {
    "token": "eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...",
    "userId": 1001,
    "nickname": "小明的猫咪",
    "avatar": "https://minio.fafa.com/avatar/user_1001.jpg",
    "isNewUser": false
  },
  "timestamp": 1692345678901
}
```

**响应字段说明**:

| 字段名 | 类型 | 说明 |
|--------|------|------|
| token | String | 认证令牌，后续请求需携带此 token |
| userId | Long | 用户 ID |
| nickname | String | 用户昵称 |
| avatar | String | 用户头像 URL |
| isNewUser | Boolean | 是否为新用户 |

**路径参数**:

| 参数名 | 类型 | 必填 | 说明 |

```json

  "message": "success",
  "data": null,
  "timestamp": 1692345678901
}
```

**业务说明**:
- 此操作为软删除，数据不会真实删除

**接口定义**: 注销当前用户账号，删除所有数据（宠物、照片、记录等）及文件，操作不可恢复

**接口地址**: `DELETE /user/account`

**是否需要认证**: 是

**请求参数**: 无

**响应示例**:

```json
{
  "code": 200,
  "message": "success",
  "data": null,
  "timestamp": 1692345678901
}
```

**业务说明**:
- 此操作会软删除（标记删除）用户的所有数据，包括：
  - 用户基础信息
  - 用户创建的所有宠物
  - 宠物的所有照片
  - 宠物的所有记录（喂食、饮水、排便、体重、事件）
  - 宠物的所有提醒
- OSS 中的文件（头像、照片）**不会被删除**，保留数据以便后续恢复
- 软删除的数据不会在应用中显示，但保留在数据库中
- 注销成功后会自动登出
- **执行此操作前，请确保已执行数据库软删除字段迁移脚本：`docs/add-soft-delete-fields.sql`**
