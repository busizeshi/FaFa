# FaFa Phase 0–10 全量接口测试文档

> 按当前仓库已实现的 Java Controller 与 Python 路由整理，实际地址以代码为准。
>
> Java：`http://localhost:8080`  
> Python：`http://localhost:8000`

## 通用约定

- Java 登录接口除外，其余业务接口需要请求头：`Authorization: {登录返回的 token}`。这里直接放 token，不要拼接 `Bearer `。
- Python `/api/**` 与 Java 回调接口需要：`X-Internal-Token: ${INTERNAL_TOKEN}`。开发环境默认值为 `fafa-internal-dev-2026`。
- Java 成功响应统一为 `{"code":0,"message":"成功","data":...}`；无数据时省略 `data`。
- 日期格式：`yyyy-MM-dd`；日期时间格式：`yyyy-MM-ddTHH:mm:ss`。
- 示例中的 ID、URL、时间请替换为实际返回值。

## Phase 0：用户系统

### 0.1 服务探活

- 接口定义：`GET`
- 接口说明：免登录检查 Java 服务是否可访问。
- 接口地址：`http://localhost:8080/api/ping`
- 传参 JSON：无请求体。
- 响应 JSON：

```json
{
  "code": 0,
  "message": "成功",
  "data": "pong"
}
```

- 接口定义：`POST`，`Content-Type: application/json`
- 接口说明：使用小程序 `wx.login()` 返回的临时 code 登录；首次登录自动注册。


## 推荐测试顺序

1. `POST /auth/wechat/login` 获取 token。
2. 带 token 测试用户、宠物、每日记录、喂食、体重和提醒接口。

4. 上传素材后保存返回的 `mediaId`，测试素材检索、详情、标签编辑和归属确认。

## 附录 B：Python AI 服务全量接口

Python 服务地址为 `http://localhost:8000`。所有 `/api/**` 接口必须携带：`X-Internal-Token: ${INTERNAL_TOKEN}` 和可选 `X-Trace-Id`；`/health` 不需要内部令牌。Python 接口返回原始 JSON，不包装 Java `Result`。

### B.1 健康检查

- 接口定义：`GET`
- 接口说明：检查 Python、Qdrant 和 DashScope 状态。
- 接口地址：`http://localhost:8000/health`
- 传参 JSON：无请求体，示例 `{}`。
- 响应 JSON：`{"status":"ok","version":"1.0.0","dependencies":{"qdrant":"ok","dashscope":"ok"}}`；依赖不可用时 `status` 为 `degraded`。

### B.2 照片/视频分析受理

- 接口定义：`POST`，`Content-Type: application/json`
- 接口说明：受理 Java 投递的照片或视频分析任务，返回 202；实际视觉理解、标签和向量化在后台执行。
- 接口地址：`http://localhost:8000/api/photos/analyze`
- 传参 JSON：

```json
{"user_id":3,"photo_id":40001,"url":"http://object-storage/fafa-media/media.mp4","media_type":"video","tags":["晒太阳"],"pet_id":1,"taken_at":"2026-08-20T15:30:00","message_id":"media-40001-analysis-001"}
```

- 响应 JSON：`{"accepted":true,"media_id":40001,"message_id":"media-40001-analysis-001"}`

### B.3 Python 语义检索

- 接口定义：`POST`，`Content-Type: application/json`
- 接口说明：使用文本向量检索 Qdrant 素材，并按用户、宠物和时间过滤。
- 接口地址：`http://localhost:8000/api/photos/search`
- 传参 JSON：`{"user_id":3,"query":"逗猫棒","limit":20,"pet_id":1,"start_date":"2026-08-01","end_date":"2026-08-23"}`

### B.4 宠物三视图向量化

### B.13 Python 接口失败响应

- 内部令牌错误：HTTP `401`，响应 `{"detail":"invalid internal token"}`。
