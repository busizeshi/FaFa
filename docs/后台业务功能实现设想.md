## 一、整体架构回顾

### 1.1 双服务架构

```
┌─────────────────────────────────────┐
│        微信小程序端                   │
└──────────────┬──────────────────────┘
               │ HTTPS
               ↓
┌─────────────────────────────────────┐

└──────────────┬──────────────────────┘
               │
    ┌──────────┴──────────┐
    ↓                     ↓

│ (业务逻辑)  │◄─MQ──┤ (AI 能力)     │
```

## 二、用户认证与权限模块

### 2.1 核心功能

1. **微信小程序登录**
2. **账密登录**（可选）
3. **Token 管理**
4. **权限控制**

### 2.2 实现思路

#### 微信登录流程

```
小程序端
  │
  ├─ wx.login() 获取 code
  │
  ↓
后端 /api/auth/wechat/login
  │
  ├─ 调用微信 API: code2Session
  │   └─ 获取 openid + session_key
  │
  ├─ 查询数据库: 根据 openid 查询用户
  │   │
  │   ├─ 存在 → 返回用户信息
  │   │
  │   └─ 不存在 → 创建新用户
  │
  ├─ 使用 Sa-Token 生成 Token
  │   └─ StpUtil.login(userId)
  │
  └─ 返回: { token, userInfo }
```

#### 关键实现点

**1. 用户表设计**
```sql
CREATE TABLE `user` (
    `id` BIGINT PRIMARY KEY AUTO_INCREMENT COMMENT '用户ID',
    `openid` VARCHAR(64) NOT NULL COMMENT '微信OpenID',
    `unionid` VARCHAR(64) NULL COMMENT '微信UnionID',
    `nickname` VARCHAR(100) NULL COMMENT '微信昵称',
    `avatar` VARCHAR(500) NULL COMMENT '微信头像URL',
    `phone` VARCHAR(20) NULL COMMENT '手机号',
    `gender` TINYINT NULL COMMENT '性别: 0-未知, 1-男, 2-女',
    `status` TINYINT NOT NULL DEFAULT 1 COMMENT '状态: 0-禁用, 1-正常',
    `register_date` DATE NOT NULL COMMENT '注册日期',
    `last_login_at` DATETIME NULL COMMENT '最后登录时间',
    `created_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    `updated_at` DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    UNIQUE KEY `uk_user_openid` (`openid`),
    KEY `idx_user_unionid` (`unionid`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';
```

**2. Sa-Token 配置要点**
- Token 存储在 Redis，支持多端登录
- 设置合理的过期时间（30天）
- 支持 Token 自动续期
- 接口权限使用注解：`@SaCheckLogin`

**3. 安全考虑**
- openid 不直接暴露给前端
- 敏感操作（换绑手机、删除账号）需二次确认
- 限制登录频率，防止恶意调用微信 API

### 2.3 数据流转

```
请求 → 拦截器检查 Token
        │
        ├─ 无 Token → 返回 401
        │
        ├─ Token 过期 → 返回 401
        │
        └─ Token 有效 
            └─ 从 Redis 获取 userId
                └─ 放入 ThreadLocal / Request Attribute
                    └─ 继续处理请求
```

### 3.3 宠物主页数据聚合实现思路

宠物主页不只是展示基础信息，需要聚合多个维度的数据：

```
GET /api/pets/{petId}/home
  │
  ├─ 查询宠物基础信息
  │
  ├─ 查询最新体重记录 (最近1条)
  │
  ├─ 查询今日提醒 (未完成的)
  │
  ├─ 查询最近动态 (最近7天的记录)
  │   ├─ 喂食记录
  │   ├─ 体重记录
  │   ├─ 照片上传
  │   └─ 事件记录
  │
  ├─ 统计数据
  │   ├─ 来到身边天数 = today - arrive_date
  │   ├─ 年龄 = today - birth_date
  │   └─ 本月记录天数
  │
  └─ AI 发现 (可选，从缓存读取)
```

**性能优化考虑**：
- 宠物主页数据可以缓存5分钟
- 使用 Redis 缓存聚合结果
- 异步计算"AI 发现"，不阻塞主页加载

### 3.4 关键业务逻辑

#### 创建宠物
```
1. 校验必填字段：name, species, gender, birth_date
2. 校验用户是否已达宠物数量上限（如5只）
3. 头像上传 OSS（如有）
4. 插入数据库
5. 初始化宠物的默认提醒（可选）
6. 返回宠物ID
```

#### 删除宠物
```
1. 校验宠物归属
2. 软删除：status = 0
3. 异步清理关联数据（可选）：
   - 提醒标记为删除
   - 照片标记为删除
   - 记录标记为删除
4. 清理相关缓存
```

### 4.5 数据一致性考虑

**问题1：体重记录同一天多次记录**
- 方案：使用 UNIQUE 约束 (pet_id, record_date)

**问题3：删除宠物后的记录**
- 记录不物理删除
- 查询时自动过滤 `pet.status = 0` 的记录

### 5.3 Python 服务：照片AI分析

#### MQ 消费者逻辑
```python
# consumer/photo_analysis.py

@消费者.订阅("photo-analysis")
async def handle_photo_analysis(message: dict):
    photo_id = message['photoId']
    pet_id = message['petId']
    url = message['url']
    
    # 1. 调用 qwen-vl-plus 理解照片
    vision_result = await call_qwen_vl(
        image_url=url,
        prompt="请描述这张宠物照片，包括：场景、宠物行为、周围物品"
    )
    # 返回示例：
    # {
    #   "scene": "阳台",
    #   "behavior": "睡觉",
    #   "objects": ["蓝色猫窝", "阳光"],
    #   "description": "一只猫趴在阳台的蓝色猫窝里睡觉，阳光洒在它身上"
    # }
    
    # 2. 生成文本描述的向量 Embedding
    embedding = await call_text_embedding(
        text=vision_result['description']
    )
    
    # 3. 存储到 Qdrant
    point_id = f"photo_{photo_id}"
    await qdrant_client.upsert(
        collection_name="pet_photos",
        points=[{
            "id": point_id,
            "vector": embedding,
            "payload": {
                "photo_id": photo_id,
                "pet_id": pet_id,
                "url": url,
                "description": vision_result['description'],
                "scene": vision_result['scene'],
                "behavior": vision_result['behavior'],
                "tags": vision_result['objects']
            }
        }]
    )
    
    # 4. 更新 MySQL photo 表
    await update_photo_ai_result(
        photo_id=photo_id,
        description=vision_result['description'],
        ai_tags=vision_result['objects'],
        ai_scene=vision_result['scene'],
        ai_behavior=vision_result['behavior'],
        embedding_id=point_id
    )
    
    logger.info(f"Photo {photo_id} analysis completed")
```

### 5.4 照片语义搜索

#### Java 接口
```java
POST /api/photos/search
{
    "petId": 123,
    "query": "找一下豆包去年夏天在阳台睡觉的照片",
```

#### Python 服务实现
```python
# api/search.py

@app.post("/api/search/photos")
async def search_photos(request: PhotoSearchRequest):
    # 1. 对用户查询进行向量化
    query_embedding = await call_text_embedding(request.query)
    
    # 2. 在 Qdrant 中搜索
    search_results = await qdrant_client.search(
        collection_name="pet_photos",
        query_vector=query_embedding,
        query_filter={
            "must": [
                {"key": "pet_id", "match": {"value": request.pet_id}}
            ]
        },
        limit=request.limit,
        score_threshold=0.7  # 相似度阈值
    )
    
    # 3. 格式化返回
    photos = []
    for result in search_results:
        photos.append({
            "photoId": result.payload['photo_id'],
            "url": result.payload['url'],
            "description": result.payload['description'],
            "scene": result.payload['scene'],
            "score": result.score
        })
    
    return {"photos": photos, "total": len(photos)}
```

### 5.5 性能优化

```java
@Scheduled(cron = "0 */5 * * * ?")  // 每5分钟执行一次
public void scanPendingReminders() {
    DateTime now = DateTime.now();
    DateTime end = now.plusMinutes(60);  // 未来1小时内的提醒
    
    List<Reminder> reminders = reminderMapper.selectList(
        new LambdaQueryWrapper<Reminder>()
            .eq(Reminder::getStatus, 0)  // 待完成
            .eq(Reminder::getNotified, 0)  // 未推送
            .between(Reminder::getRemindTime, now, end)
    );
    
    for (Reminder reminder : reminders) {
        // 推送小程序订阅消息
        wechatService.sendSubscribeMessage(
            reminder.getUserId(),
            reminder.getPetId(),
            reminder.getTitle(),
            reminder.getRemindTime()
        );
        
        // 更新状态为已推送
        reminderMapper.updateById(
            reminder.setNotified(1)
        );
    }
}
```

```java
public DateTime calculateNextRemindTime(Reminder reminder) {
    DateTime current = new DateTime(reminder.getRemindTime());
    
    return switch (reminder.getRepeatType()) {
        case 1 -> current.plusWeeks(1);  // 每周
        case 2 -> current.plusMonths(1);  // 每月
        case 3 -> current.plusDays(reminder.getRepeatInterval());  // 每N天
        case 4 -> current.plusMonths(reminder.getRepeatInterval());  // 每N月
        case 5 -> current.plusYears(1);  // 每年
        default -> null;
    };
}
```

#### Agent 工作流（LangGraph）
```python
# agent/graph.py

from langgraph.graph import StateGraph, END
from langchain_community.chat_models import ChatTongyi

class AgentState(TypedDict):
    messages: List
    pet_id: str
    tools_called: List[str]

# 初始化 LLM
llm = ChatTongyi(
    model="qwen3.7-flash",
    dashscope_api_key=settings.dashscope_api_key
)

# 绑定工具
llm_with_tools = llm.bind_tools([
    get_pet_profile,
    get_weight_history,
    get_feeding_history,
    search_photos
])

def call_model(state: AgentState):
    """调用 LLM 决策"""
    response = llm_with_tools.invoke(state['messages'])
    return {"messages": [response]}

def should_continue(state: AgentState):
    """判断是否需要调用工具"""
    last_message = state['messages'][-1]
    if hasattr(last_message, 'tool_calls') and last_message.tool_calls:
        return "tools"
    return END

async def call_tools(state: AgentState):
    """执行工具调用"""
    last_message = state['messages'][-1]
    tool_results = []
    
    for tool_call in last_message.tool_calls:
        tool_name = tool_call['name']
        tool_args = tool_call['args']
        
        # 自动注入 pet_id
        if 'pet_id' not in tool_args:
            tool_args['pet_id'] = state['pet_id']
        
        # 执行工具
        result = await execute_tool(tool_name, tool_args)
        tool_results.append(ToolMessage(
            tool_call_id=tool_call['id'],
            content=json.dumps(result, ensure_ascii=False)
        ))
    
    return {
        "messages": tool_results,
        "tools_called": [tc['name'] for tc in last_message.tool_calls]
    }

# 构建图
workflow = StateGraph(AgentState)
workflow.add_node("agent", call_model)
workflow.add_node("tools", call_tools)
workflow.set_entry_point("agent")
workflow.add_conditional_edges("agent", should_continue)
workflow.add_edge("tools", "agent")

agent = workflow.compile()
```
