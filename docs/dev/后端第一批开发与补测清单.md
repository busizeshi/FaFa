## 3. 实现中的关键约定

- Java 响应类型保持 R<T>，JSON 成功 code 为 "0"，错误沿用 FAFA-* 线码。
- 密码哈希是 Argon2id，输入不静默截断；验证码保存 HMAC，重置票据保存摘要。
- 注册的挑战消费、账号、资料、同意记录在一个数据库事务里；错误验证码次数提交后才返回错误，不被异常回滚。
- 每次登录和密码重置推进数据库 authVersion，Token Session 记录对应代际；有效身份检查同时验证账号状态与代际。
- 注册响应丢失可用刚设置的密码登录；不缓存带 Token 的通用幂等响应，也不重复创建用户。
- 注册已提交、Redis 会话创建失败时，返回 201、session=null、nextAction=LOGIN，账号不会被回滚消失。
- 密码重置成功而 Redis 清理失败时仍返回成功；旧会话因代际检查失效，留下安全告警供排查。
- 邮件发送与数据库事务分开；SMTP 接收后进程崩溃可能留下不可用验证码，用户需重发。本批没有声称邮件具有端到端只发送一次保证。
- 正式迁移不自动发布测试协议；没有已发布 TERMS/PRIVACY 时注册返回协议版本冲突，不能绕过同意检查。

本批修复了实际测试发现的 Springdoc 2.3.0 与 Spring 6.2 的 ControllerAdviceBean 运行时不兼容，统一 Springdoc 到 2.8.17；没有更改已有 Boot/Cloud/Dubbo 主版本。参考[Springdoc 兼容说明](https://springdoc.org/v2/)和[官方问题记录](https://github.com/springdoc/springdoc-openapi/issues/3041)。

Sa-Token 固定版本 1.44.0；密码哈希按[Spring Security 官方密码存储说明](https://docs.spring.io/spring-security/reference/features/authentication/password-storage.html)接入 BouncyCastle。开发邮件捕获使用 [Mailpit v1.27.8](https://github.com/axllent/mailpit/releases/tag/v1.27.8)，本轮未拉取或运行该镜像。

| 变量 | 含义 |

生产 HMAC secret/mailFrom 为空时配置校验失败，不会悄悄使用默认认证秘密。

开发随机秘密可在 PowerShell 中生成并仅写入当前进程环境：

~~~powershell
$authBytes = New-Object byte[] 32
$authRandom = [System.Security.Cryptography.RandomNumberGenerator]::Create()
$authRandom.GetBytes($authBytes)
$env:FAFA_AUTH_HMAC_SECRET = [Convert]::ToBase64String($authBytes)
$authRandom.Dispose()
~~~

不要打印秘密或提交 .env；当前终端退出后，环境值不自动持久化。以后重启补测应采用自己的安全本地配置。

## 6. API 客户端补测数据

导入 [app-v1.yaml](../../contracts/openapi/app-v1.yaml)，设 baseUrl 为测试 Gateway 的 /api/v1。使用仅用于测试的邮箱和密码，依次执行：

1. GET legal-documents，取得 TERMS/PRIVACY 的实际 version。
2. POST email-challenges，purpose=REGISTER，记录 challengeId。
3. 从 Mailpit/测试收件箱读取 code；POST registrations，提交两次密码、legalVersions 和 device。
4. 保存 data.session.token；Authorization: Bearer Token 调用 me、bootstrap、me/sessions。
5. 新 device 登录，旧 Token 请求应 401。
6. RESET_PASSWORD challenge → password-reset-tickets → password-resets，检查旧会话和旧密码均不可用。
7. 用新密码登录，再退出；Token 不可再次访问 me。

device 示例：

~~~json
{"deviceId":"android-test-device-a","deviceName":"Android test device A"}
~~~

首次注册可能在账号已提交后返回 session=null、nextAction=LOGIN；应检查账号存在并测试正常登录恢复，不能当作未注册再次创建。
