# FaFa 日记 APP 功能预期描述

> 文档用途：说明 APP 的模块边界、用户可完成的任务、页面交互路径和业务规则，供产品讨论、原型核对与后续开发拆分使用。  
> 主要依据：《项目初步设计.md》（2026-10-15 修订）与《APP页面结构与交互说明.md》。  
> 产品定位：帮助猫狗主人和共同照护者记录宠物生活与照护、管理提醒、找回资料；AI 负责整理与检索，不替代兽医。

## 1. 产品目标与模块划分

APP 首期围绕三件事构建闭环：

1. 记得住：快速记录喂食、饮水、体重、预防照护、用药、就医和日常变化。
2. 找得到：按宠物、日期、事件和照片找回记录与素材。
3. 不漏掉：由主人设定或确认照护事项，并能查看、完成、延期、跳过或调整。

根据指定的 Pen 模块节点，业务功能分为以下八个模块。八个模块是功能边界，不代表 APP 有八个一级导航入口。主导航仍按初步设计保持首页、记录、相册、AI 助手、我的五项；宠物管理和社区/分享作为从“我的”进入的二级功能，账号认证作为进入 APP 的流程。

| Pen 节点 | 模块 | 主要目标 | 预期阶段 |
|---|---|---|---|
| d2l2gh | 启动、注册与登录 | 建立账号、验证邮箱、恢复账号访问 | P0 |
| ENG3i | 宠物管理 | 管理多只宠物档案、当前宠物和档案状态 | P0；家庭协作 P1 |
| UvQJO | 首页 | 查看当前宠物的照护概览并快速开始常用任务 | P0 |
| Gt499 | 我的与用户中心 | 管理个人设置，并进入宠物管理、协作、隐私和账号功能 | P0/P1 |
| qevt3 | 记录与养护 | 记录日常与健康事实，管理计划、提醒和趋势 | P0/P1 |
| XfDUi | 相册与素材 | 私密保存、整理、搜索宠物照片和视频 | P0；语义搜索 P1 |
| rkU6a | AI 助手 | 在用户授权范围内查询、整理、检索和生成待确认草稿 | P1 |
| dhxdO | 社区与分享 | 分享照护资料；在治理能力具备后提供公开社区 | 私人分享 P1；公开社区 P2 |

### 1.1 版本边界

- P0 是不依赖 AI 或社区也能完整使用的首发闭环：账号、宠物档案、首页、手动记录、提醒、相册基础管理、隐私和账号管理。
- P1 扩展 AI 整理与问答、语义素材检索、周报/月报、家庭共同照护和临时照护分享。
- P2 包含公开宠物社区、3D 形象和 AI 创作等需要额外技术能力、合作方或持续运营治理的功能。社区审核能力未准备好时，不开放公开发布。

## 2. 全局交互约定

| 主题 | 交互规则 |
|---|---|
| 导航 | 首页、记录、相册、AI 助手、我的为五个主入口。详情页、表单页、筛选面板和确认弹层返回触发它们的页面；系统返回与页内返回一致。 |
| 当前宠物 | 首页、记录、相册和 AI 共享当前宠物上下文。切换宠物后，列表、趋势、搜索范围和新建记录目标一起更新。表单中有未保存内容时，先让用户保存草稿、放弃更改或取消切换。 |
| 数据来源 | 清楚区分主人填写、实际测量、兽医材料、AI 识别待核对和 AI 摘要。主观估计不能显示成实测数据，AI 推测不能写成宠物事实。 |
| 保存与修改 | 保存成功后说明保存对象和去向；失败保留用户输入并提供重试或手动保存。离开有未保存更改的页面时，提供保存草稿、放弃和继续编辑。 |
| 删除与归档 | 删除前指出宠物、记录、附件或分享关系受何影响。能用归档保留历史资料时优先提供归档；永久删除应有明确确认。 |
| 隐私与授权 | 宠物照片、就诊材料和家庭照护记录默认私密。上传、交给 AI 处理、加入报告或公开分享前，展示使用范围和实际要处理的内容。 |
| 空态和错误 | 列表、搜索和上传均需有空数据、无结果、加载中、失败、权限拒绝和重试路径；失败时不得显示为已保存或已分享。 |
| 权限 | 在用户首次使用相机、照片或通知等功能时解释用途再申请。拒绝后不反复打断，并提供可用的手动或只读路径。 |

## 3. 模块功能与交互

### 3.1 启动、注册与登录（d2l2gh）

**目标：** 让用户安全进入自己的宠物资料；首次注册不以填写非必要个人信息为前提。

| 功能 | 用户交互 | 交互逻辑与规则 |
|---|---|---|
| 启动路由 | 打开 APP 后进入欢迎、登录或首页 | 未登录进入欢迎/登录；有效会话返回上次页面或原深链接目标；登录过期时登录后恢复原目标。已有草稿不能因重新登录而静默丢失。 |
| 注册 | 填写邮箱、密码、确认密码并同意必要协议，提交注册 | 校验邮箱格式、密码规则和两次密码一致性。邮箱已注册时给出登录或找回密码入口。协议不得预勾选；用户可先查看协议再返回。 |
| 邮箱验证 | 查看部分遮蔽的邮箱，等待验证或申请重发 | 显示发送状态和重发等待时间；允许修改邮箱或回到注册。验证链接过期、邮件未到或发送失败时提供重试路径。邮箱服务商需在上线前确认境内可用性。 |
| 登录 | 输入邮箱和密码，可显示/隐藏密码；提交登录 | 邮箱或密码错误时保留邮箱并说明如何找回；网络失败可重试。成功后回到原来要访问的页面，否则进入首页。 |
| 找回与重置密码 | 输入邮箱申请重置；从邮件链接设置新密码 | 申请结果使用一致提示，避免泄露邮箱是否注册。链接过期或已使用时重新申请；重置成功回到登录页。 |
| 首次进入与添加宠物 | 验证后可添加第一只宠物，也可稍后添加 | 最短建档只要求宠物昵称和猫/狗类型，其余信息可以跳过或以后补充。未知的生日、品种等保持未知，不要求用户猜填。初步设计已取消注册时强制采集宠物三视图，也不依赖三视图才能使用记录功能。 |

**关键路径：** 欢迎 → 注册 → 邮箱验证 → 可选添加宠物 → 首页。已有账号：欢迎 → 登录 → 首页或恢复原目标。

### 3.2 宠物管理（ENG3i）

**目标：** 管理一个账号下的多只宠物，并让记录始终归属于明确的宠物。

该模块由“我的”进入管理列表；首页和需要宠物上下文的页面也可通过当前宠物选择器切换。

| 功能 | 用户交互 | 交互逻辑与规则 |
|---|---|---|
| 宠物列表与切换 | 查看活跃宠物，点选一只设为当前宠物；可展开归档列表 | 当前项有明确状态。切换后刷新关联列表和首页内容。表单有未保存内容时，询问保存草稿、放弃或取消切换。归档宠物只读，不可作为普通新记录目标。 |
| 新增宠物 | 选择猫/狗并填写昵称；按需补充生日/估算年龄、到家日期、品种、性别、绝育状态、照片和备注 | 首期聚焦猫狗。品种、生日、性别、绝育和备注可选；年龄估算需标明是估算。照片可跳过。保存后进入档案详情，并可设为当前宠物。 |
| 档案详情 | 查看宠物基本资料、最近体重、照护成员和关联功能入口 | 最近体重从带日期的体重记录读取，不把静态档案字段当成最新测量。缺失资料显示未填写；体重卡进入趋势或原始记录。 |
| 编辑资料 | 进入编辑页修改基本信息或照片，保存或取消 | 保存成功后同步更新各页面的名称和头像，不改写既有记录中的测量值或历史日期。生日未知可以留空。 |
| 归档与恢复 | 对不再活跃的宠物选择归档；在归档列表中查看或恢复 | 归档保留用户选择保留的记录与素材，停止将该宠物作为默认新建目标。恢复后回到活跃列表，是否设为当前宠物由用户决定。 |
| 删除宠物 | 从详情或更多菜单选择删除，阅读影响后确认 | 先说明关联记录、附件、家庭成员权限和公开帖子的影响；可归档时提供归档替代。永久删除需按账号数据删除规则清理关联文件和索引，不能留下可访问的悬空链接。 |
| 家庭照护成员（P1） | 从档案进入成员管理、邀请或修改权限 | 邀请前选择宠物、可编辑/只读角色、资料范围和有效期；邀请对象接受后才取得权限。成员变更显示操作者与时间，主人可以撤销。 |

### 3.3 首页（UvQJO）

**目标：** 一眼了解当前宠物今天要处理的事项，并在少量操作内完成记录。

| 功能 | 用户交互 | 交互逻辑与规则 |
|---|---|---|
| 当前宠物与今日概览 | 查看当前宠物、日期和待办摘要；点宠物入口切换 | 概览跟随当前宠物。切换后待办、最近动态、指标和快捷记录目标一致更新。 |
| 今日待办 | 点待办查看详情；选择完成、延期、跳过或编辑 | 首页只呈现主人已设置或确认的提醒，不把 AI 推测显示为健康异常。延期必须选新时间；跳过可保留状态，逾期事项不静默消失。 |
| 快速记录 | 从喂食、饮水、体重、预防照护、用药、就医、观察或随手记等入口进入专用表单 | 打开后预填当前宠物与合理的默认时间；用户可修改。保存成功进入记录详情，并可继续记录或回首页。 |
| 最近动态 | 点最近记录或素材进入对应详情 | 显示真实记录时间与来源。删除或权限变化后，卡片刷新并给出当前状态。 |
| 指标趋势入口 | 点体重、实际喂食量等已形成连续数据的指标 | 显示时间范围、单位、来源和原始数据点；点数据点回对应记录。数据不足时展示已有值和新增记录入口，主观饮水等级不生成精确数值曲线。 |
| AI 今日整理（可关闭） | 用户主动打开摘要或关闭该卡片 | 只总结已经保存的事实并能查看引用记录；不得把未记录说成异常、缺失或未完成照护。没有资料时说明资料不足。 |
| 首页空态 | 无宠物、无提醒、无记录或无相册素材时使用相应入口 | 每种空态给出明确的最小下一步，例如添加宠物、创建提醒或新增记录；不显示无法操作的占位卡片。 |

### 3.4 我的与用户中心（Gt499）

**目标：** 集中管理个人设置，并作为宠物管理、社区/分享、隐私和账号操作的入口。

| 功能 | 用户交互 | 交互逻辑与规则 |
|---|---|---|
| 个人资料 | 查看或编辑昵称、头像、邮箱、时区等少量必要信息 | 修改邮箱需重新验证；时区影响提醒显示和时间解释。删除与照护无关的性别、年龄、MBTI 等必填项，不收集无明确用途的资料。 |
| 宠物管理入口 | 从“我的”进入 ENG3i 宠物列表 | 与首页当前宠物保持一致；从宠物详情返回时回到“我的”原位置。 |
| 家庭协作入口（P1） | 邀请照护者、查看成员、改权限、撤销访问 | 显示成员能访问哪些宠物和资料。权限修改或撤销后，相关共享入口立即反映新状态。 |
| 临时照护清单（P1） | 选宠物、照护期限和需要交给照护者的内容，预览后分享 | 只包含主人勾选的喂食、饮水、处方原文、注意事项和联系人等信息；不自动加入家庭住址或无关个人资料。分享链接可查看有效期和撤销状态。 |
| 社区与分享入口 | 进入 dhxdO 社区/分享功能 | 私密资料分享与公开社区分开呈现；公开内容的发布、可见范围和审核状态需在对应功能内确认。 |
| 提醒偏好 | 设置免打扰时间、默认提前量、类别开关和通知状态 | 系统通知关闭时仍保留应用内待办；首次创建提醒时说明通知用途并请求授权，拒绝后不循环请求。 |
| 隐私与 AI 设置 | 查看资料用途、AI 处理说明、会话保存与素材检索授权 | 个人记录检索、图片语义搜索、包装识别和历史保存分别说明。关闭 AI 处理后仍可手动记录和按条件查找。 |
| 账号安全与数据 | 修改密码、退出、申请资料副本/导出、注销 | 退出时说明本地草稿和云端资料状态。注销前列出宠物、共享权限、媒体、帖子和 AI 会话的影响，并按步骤确认；未实现的数据请求能力不展示为已可用按钮。 |
| 帮助与协议 | 打开用户协议、隐私政策、帮助和反馈入口 | 对应内容可从注册、AI 与社区流程返回。反馈提交应显示结果；紧急动物医疗问题不引导至普通客服排队。 |

### 3.5 记录与养护（qevt3）

**目标：** 以宠物为单位记录照护事实，支持之后查找、编辑、查看趋势和处理提醒。

#### 时间线、记录和详情

| 功能 | 用户交互 | 交互逻辑与规则 |
|---|---|---|
| 时间线 | 按时间查看当前宠物的喂食、健康与日常记录；可搜索、按类型/日期/宠物筛选 | 应用筛选后保留条件和结果数；清空恢复默认列表。无记录、无结果和加载失败分别显示下一步。列表项进入详情。 |
| 新增记录 | 从首页快捷入口或记录页选择类型，填写类型专属字段后保存 | 默认填入当前宠物和当前时间。数量、单位、事实来源及选填项按记录类型校验。保存成功后进入详情并刷新时间线、首页待办或趋势。 |
| 记录类型 | 喂食、饮水、体重与体况、疫苗、驱虫、用药、就医、洗护、日常观察、纪念/成长和文字随手记 | 只提供当前产品实际支持的类型。字段随类型变化；不同记录的来源、量纲、提醒和附件规则不能互相混用。 |
| 记录详情 | 查看宠物、日期、字段、附件、来源以及创建/修改时间 | 显示主人填写、实际测量、兽医材料或 AI 确认结果等来源；AI 草稿不能作为正式记录混入时间线。 |
| 编辑和删除 | 从详情进入预填表单，修改后保存；删除时查看关联对象并确认 | 编辑保留修改时间与来源信息。删除需说明关联提醒和附件如何处理，默认不连带删除无关记录；删除后相关列表及时刷新。 |
| 附件 | 从记录表单添加照片、视频或文件；详情中预览 | 在本地或系统选择器中选择后展示文件状态。取消不影响记录填写；失败可单项重试或移除。附件关联和可见范围明确，不默认公开。 |

#### 记录类型字段和业务逻辑

| 类型 | 用户填写或选择 | 业务逻辑 |
|---|---|---|
| 喂食 | 食品、时间、计划投喂量、实际投喂量、实际食用情况、补充说明、附件 | 计划值和实际值分开保存；支持按计划或上次记录复用。部分吃完、未吃等情况不可伪装成已吃完。 |
| 饮水 | 时间、实测量与单位（可选）、主人观察程度（少/一般/多/不清楚）、说明 | 实测数据和主观观察分开保存；主观等级不换算成毫升，也不产生精确量趋势。 |
| 体重与体况 | 日期、体重和单位、称重来源、BCS/MCS（选填）、说明 | 体重必须大于零，展示来源和日期。BCS/MCS 为可选评估，不替代兽医判断；趋势可回到原始测量记录。 |
| 疫苗 | 疫苗名称、日期、机构或兽医、批次/证明、下次日期 | 下次接种日期由主人或兽医资料提供并由主人确认；系统不自行推导接种周期。 |
| 驱虫 | 产品名称、使用日期/方式、相关体重、来源说明、附件、下次日期（选填） | 不由 AI 推荐产品或剂量。仅对主人确认的日期创建提醒。 |
| 用药 | 药品、处方或主人来源、处方原文、开始/结束日期、执行时间、附件 | 记录处方原文而非 AI 推算的剂量。信息不足时可保存文字资料，但不能创建缺少频次依据的剂量提醒。 |
| 就医 | 日期、机构/兽医、主人主诉、检查/处方附件、兽医提供的诊断与建议原文、复诊日期 | 明确区分主人描述和医院材料。FaFa 保存资料，不出具诊断；复诊提醒需确认。 |
| 日常观察 | 精神、食欲、排便、皮毛、活动等主题，主人描述、选填等级与附件 | 记录以“主人观察”呈现，不改写成诊断。自由文字保留原文。 |
| 洗护 | 洗澡、梳毛、剪指甲、清洁或自定义项目、日期、执行人、备注、下次提醒 | 下次日期为可选且由主人确认；保存后可以关联提醒。 |
| 纪念/成长 | 到家、生日、训练、旅行、纪念日或自定义标题、日期、内容和媒体 | 可选择是否纳入报告或分享；素材可从相册选择，也可稍后补充。 |
| 文字随手记 | 宠物、时间和自由文本；可选附件 | 不使用 AI 时也能直接保存。请求 AI 整理时先生成待确认草稿，正式原文保留。 |

#### 喂食计划与食品档案

| 功能 | 用户交互 | 交互逻辑与规则 |
|---|---|---|
| 食品档案 | 搜索或新增常用食品，填写名称、品牌、包装重量、包装能量值及单位，保存来源和包装照片 | 允许手工录入。包装识别只能预填字段，用户核对名称、数值和单位后才能保存；缺失项保持空白，不自动补成看似准确的营养数据。 |
| 创建喂食计划 | 依次选择宠物和目标、食品与能量信息、每日时段和每次份量，复核后保存 | 估算展示输入项、采用公式/资料来源和仅供参考说明。健康异常、特殊年龄阶段、怀孕哺乳或处方饮食需由兽医确认。AI 不后台修改计算结果。 |
| 查看和修改计划 | 查看食品、周期、每天/每次份量及提醒；可编辑、暂停、恢复或结束 | 修改说明何时生效以及对关联提醒的影响；计划更新不改写旧的实际喂食记录。可从计划进入“记一次喂食”，但仍需填写实际情况。 |

#### 提醒与趋势

| 功能 | 用户交互 | 交互逻辑与规则 |
|---|---|---|
| 提醒日历与列表 | 在日期或今天/未来/逾期/已完成列表中查看事项，按宠物、类型和状态筛选 | 展示提醒来源和关联记录。提醒属于用户设置或确认的任务；无事项的日期也可新增。 |
| 新建/编辑提醒 | 填写标题、宠物、日期/时间、重复规则、提前量、结束条件和关联记录，预览后保存 | 支持一次性或重复提醒。月末规则预览后续触发日期；时区变化后保留原意图并清楚展示本地时间。 |
| 处理提醒 | 从首页、日历或提醒详情选择完成、稍后、跳过、暂停或编辑 | 延期必须选新时间；跳过可填原因。处理成功同步更新首页与日历并保留状态。通知权限关闭时应用内待办仍有效。 |
| 指标趋势 | 查看有足够连续数据的体重、实际喂食量或实测饮水量，切换时间范围 | 显示单位、数据点、记录来源与日期；点击数据点打开原记录。数据点不足时展示已有记录和添加入口，不外推或补造曲线。 |
| 周报/月报（P1） | 选择宠物、周期、资料范围和照片，生成预览，核对来源后编辑或分享 | 只汇总真实记录；数据不足明确显示缺项。AI 摘要可修改，所有事实可定位到来源记录。分享前由主人选择材料和范围。 |

### 3.6 相册与素材（XfDUi）

**目标：** 私密保存和整理宠物的照片、视频及相关素材，并能按条件找回。

| 功能 | 用户交互 | 交互逻辑与规则 |
|---|---|---|
| 相册浏览 | 按日期浏览照片与视频，切换当前宠物，查看素材详情 | 支持宠物、日期、媒体类型和标签筛选。未关联宠物的素材可继续留在相册，不能擅自猜测归属。 |
| 添加素材 | 调用系统相机或照片选择器，多选后添加宠物、日期、标签、备注和可见范围 | 默认私密。权限在首次添加时解释；取消选择回到原位置。开始上传前明确会处理哪些文件。 |
| 上传状态 | 查看逐项进度、成功和失败；失败项可重试或移除 | 一项失败不回滚其他已成功文件。离开页面后应能恢复状态；失败未重试前不得显示上传成功。 |
| 编辑素材信息 | 修改宠物关联、日期、标签、备注或关联记录 | 更改宠物关联时说明目标宠物；修改不会改变照片原始内容。关联记录删除后相册素材仍按用户选择保留或解除关联。 |
| 搜索 | P0 以关键词、宠物、日期、媒体类型和标签查找；P1 增加自然语言语义搜索 | P1 结果说明匹配条件，支持纠正标签或宠物关联。语义相似度不代表识别出同一只宠物，也不作为身份事实。 |
| 素材详情与使用 | 预览媒体、查看来源和关联记录；可编辑、删除、加入报告或发起分享 | 分享前显示目标范围与将包含的内容。删除素材说明是否保留关联记录；清除文件时同步处理业务元数据和搜索索引。 |
| 搜索失败与索引状态（P1） | 查看处理中、完成、失败或不可用状态；选择重试或普通筛选 | AI 索引不可用不影响相册浏览和关键词筛选；不会将失败误报为没有素材。 |

### 3.7 AI 助手（rkU6a）

**目标：** 在用户明确发起和授权的范围内，帮助查询已记录事实、整理资料和生成可确认草稿。

| 功能 | 用户交互 | 交互逻辑与规则 |
|---|---|---|
| 基于记录问答 | 选择当前宠物并提问，阅读答复和引用来源 | 根据个人记录的答复标注宠物、日期和来源，点击引用可回原记录。没有依据时明确表示资料里没有；一般知识与个人记录结论分开展示。 |
| 一般照护知识 | 提问常见日常照护问题 | 给出一般信息并提示适用边界。AI 不诊断疾病、不处方、不建议自行停药或改剂量；严重症状提示尽快联系动物诊疗机构。 |
| 自然语言整理为记录 | 输入文字或选择资料，请求提取宠物、日期、类别和数值 | 生成可修改的字段草稿并标出待核对项；低置信度字段不静默入库。用户可逐项修改、删掉错误字段、拆成多条或取消。只有确认后才创建正式记录。 |
| AI 生成提醒草稿 | 根据已记录内容整理可能需要的提醒 | 仅展示建议和来源，不自动创建或改变提醒；用户确认宠物、日期和重复规则后才保存。医疗周期不得由 AI 推导。 |
| 周报/月报摘要 | 从已保存记录生成可编辑的摘要 | 显示摘要所依据的记录，主人可编辑或移除错误内容。生成失败时保留配置和已有资料，不阻断手动报告。 |
| 素材语义检索 | 输入自然语言描述查找相册素材 | 返回匹配素材并展示日期、宠物关联和匹配依据；用户可反馈无关结果。不得宣称识别了宠物身份、疾病或照片中的确定事件。 |
| 会话与隐私 | 查看或清理会话，阅读本次 AI 数据使用说明并管理授权 | 调用前解释将发送的必要资料、用途和保存方式。用户可分别关闭个人记录检索、图片搜索或历史保存；关闭后手动记录和筛选仍可使用。 |
| 失败与安全状态 | 在网络失败、服务不可用、无来源或请求不支持时处理 | 保留用户输入，提供重试、编辑或手动保存。只读查询不修改数据；创建、编辑、删除记录或提醒必须先让用户检查并确认。 |

### 3.8 社区与分享（dhxdO）

**目标：** 让用户按自己选择的范围分享照护资料；公开社区作为后续能力，在内容治理准备完成后开放。

私人分享与公开发布是不同任务，入口、预览和授权不得混为一体。

#### 私人分享与照护协作（P1）

| 功能 | 用户交互 | 交互逻辑与规则 |
|---|---|---|
| 分享报告或资料 | 从报告、素材或照护清单选择系统分享；分享前预览内容 | 默认不公开。用户逐项选择文字、图片、指标和宠物信息；取消系统分享回到预览，不得推断外部平台已发布。 |
| 邀请家庭成员 | 从“我的”或宠物档案选择宠物、角色、资料范围和有效期，再生成链接/码 | 被邀请人接受后生效。邀请可复制、查看、撤销；过期、撤销和已接受状态分开显示。 |
| 临时照护清单 | 选择照护日期和要提供的喂食、饮水、处方说明、注意事项等，预览后分享 | 处方剂量按原始资料呈现，不由 AI 生成。预览时可删去敏感信息；链接有有效期并可撤销。 |
| 权限撤销 | 在成员或分享管理页选对象并确认撤销 | 说明撤销的账号、宠物和资料范围。撤销后原入口不再返回受限内容；审计记录保留必要的变更时间和操作者。 |

#### 公开社区（P2，治理能力就绪后）

| 功能 | 用户交互 | 交互逻辑与规则 |
|---|---|---|
| 内容流 | 在“关注”或“最新”流中浏览帖子，进入作者或帖子详情 | 不使用完全随机流。私密档案不进入公开推荐；帖子显示作者、关联宠物、可见范围和审核状态。 |
| 发布帖子 | 选择可公开的照片/视频或成长记录，编辑正文与话题，设置可见范围，预览后发布 | 未选中的档案不自动带入。范围可选公开、仅关注者或仅自己。发布后根据审核状态显示处理中、公开或受限，不把待审核内容标成已公开。 |
| 点赞、评论、收藏与关注 | 在帖子或主页进行互动，查看互动状态 | 点赞可取消；评论支持失败保留草稿和举报；取消关注或屏蔽有即时反馈。源内容被删除或权限收紧后，历史入口显示不可见状态。 |
| 举报、屏蔽与申诉 | 选择帖子、评论或用户，选择原因后提交；可维护屏蔽名单 | 不向被举报者泄露举报人身份。用户可查看处理状态并按规则申诉；屏蔽与解除屏蔽均清楚说明影响。 |
| 内容治理依赖 | 用户正常发布前由平台审核、举报处理、账号处置和申诉流程支撑 | 公开社区至少需要待审队列、举报受理、处置记录、屏蔽和申诉能力及运营责任人。准备完成前，社区入口可以展示说明或保持关闭，不提供无法完成的发布路径。 |

## 4. 关键跨模块流程

1. **首次使用：** 欢迎 → 注册 → 邮箱验证 → 可选添加宠物 → 首页。建档字段可以后补充，跳过添加也能进入有引导的首页。
2. **快速记录喂食：** 首页选择喂食 → 检查宠物和时间 → 填食品、投喂/食用情况 → 保存 → 记录详情；保存后刷新首页与时间线。
3. **切换宠物：** 任一当前宠物入口 → 选择目标 → 无未保存内容则切换并刷新；有草稿则先选择保存、放弃或取消。
4. **管理健康资料：** 记录页选择疫苗、驱虫、用药或就医 → 输入原始事实/附件 → 确认是否创建主人设定的提醒 → 保存并查看详情。
5. **处理提醒：** 首页或日历打开提醒 → 完成、延期、跳过或编辑 → 确认结果 → 首页、日历和提醒详情同步更新。
6. **建立喂食计划：** 选择宠物与目标 → 选择食品并核对能量信息 → 设置时段与份量 → 复核估算依据 → 保存；计划值不覆盖实际记录。
7. **从相册加入报告：** 相册筛选或搜索 → 素材详情 → 加入报告 → 报告预览与来源核对 → 选择分享范围 → 调用系统分享。
8. **AI 转换为记录：** 输入自然语言 → 生成待核对草稿 → 修正字段和来源 → 用户确认写入 → 记录详情；取消或失败不改动正式数据。
9. **临时照护分享：** 我的/宠物档案 → 选择宠物、期限和资料 → 预览删除敏感内容 → 确认分享 → 可查看状态或撤销。
10. **公开社区发帖（P2）：** 社区 → 选素材 → 编辑文字 → 设可见范围 → 预览 → 发布并查看审核状态；审核和举报能力未就绪时不开放该路径。

## 5. 明确不纳入当前承诺的能力

以下内容不应被现有页面入口暗示为已可用功能，需有单独的能力评估和产品决策后再扩展：

- AI 动物疾病诊断、处方建议、自动改药量或自动调整喂养数值。
- 从普通包装照片恢复完整配方或准确判断食品是否适合某只宠物。
- 通过普通照片或三视图准确识别宠物个体、自动关联宠物身份或生成可靠 3D 模型。
- 自动生成并发布照片翻转视频或 AI 视频。
- 线上兽医问诊、商品交易、附近服务/医院、智能设备接入和机器学习喂养优化。
- 没有审核、举报、屏蔽、处置与申诉能力支撑的公开社区。
