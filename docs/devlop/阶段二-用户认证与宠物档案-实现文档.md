### 2.3 应用服务

#### AuthApplicationService
**文件**：`application/service/AuthApplicationService.java`

**核心业务逻辑**：

```java
@Transactional
public LoginResult wechatLogin(String code) {
    // 1. 调用微信接口获取 openid
    Code2SessionResult sessionResult = wechatMiniAppService.code2Session(code);
    
    // 2. 查询或创建用户
    Optional<User> userOpt = userRepository.findByOpenid(openid);
    if (userOpt.isPresent()) {
        // 已存在，更新最后登录时间
        user = userOpt.get();
        user.updateLastLogin();
        userRepository.update(user);
    } else {
        // 新用户，创建用户记录
        user = User.builder()
                .openid(openid)
                .unionid(unionid)
                .status(UserStatus.NORMAL)
                .registerDate(LocalDate.now())
                .build();
        user = userRepository.save(user);
    }
    
    // 3. 检查用户状态
    if (!user.isNormal()) {
        throw new BusinessException("账号已被禁用");
    }
    
    // 4. Sa-Token 登录
    StpUtil.login(user.getUserId().getValue());
    String token = StpUtil.getTokenValue();
    
    return LoginResult.builder()
            .token(token)
            .userId(userId)
            .isNewUser(isNewUser)
            .build();
}
```

**其他方法**：
- `getCurrentUser()`: 获取当前登录用户
- `logout()`: 登出

**应用服务方法**：`PetApplicationService.sortPets()`

**核心逻辑**：
```java
public void sortPets(Long userId, List<Long> petIds) {
    for (int i = 0; i < petIds.size(); i++) {
        Long petId = petIds.get(i);
        Pet pet = petRepository.findById(new PetId(petId))
                .orElseThrow(() -> new BusinessException("宠物不存在"));
        
        // 权限校验
        if (!pet.getUserId().equals(userId)) {
            throw new BusinessException("无权修改该宠物");
        }
        
        // 更新排序字段
        pet.setSortOrder(i);
        petRepository.save(pet);
    }
}
```
