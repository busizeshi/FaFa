### 2.2 核心配置（application.yml）

```yaml
server:
  port: 8080
  servlet:
    context-path: /api

spring:
  application:
    name: fafa-java-service
  
  # 数据源配置
  datasource:
    driver-class-name: com.mysql.cj.jdbc.Driver
    url: jdbc:mysql://${MYSQL_HOST:localhost}:${MYSQL_PORT:3306}/${MYSQL_DATABASE:fafa}
    username: ${MYSQL_USERNAME:root}
    password: ${MYSQL_PASSWORD:password}
    hikari:
      maximum-pool-size: 10
      minimum-idle: 5
  
  # Redis 配置
  data:
    redis:
      host: ${REDIS_HOST:localhost}
      port: ${REDIS_PORT:6379}
      password: ${REDIS_PASSWORD:}

# MyBatis Plus
mybatis-plus:
  configuration:
    map-underscore-to-camel-case: true
  global-config:
    db-config:
      id-type: auto

# Sa-Token
sa-token:
  token-name: Authorization
  timeout: 604800  # 7天
  is-concurrent: true

# MinIO
minio:
  endpoint: ${MINIO_ENDPOINT:http://localhost:9000}
  access-key: ${MINIO_ACCESS_KEY:minioadmin}
  secret-key: ${MINIO_SECRET_KEY:minioadmin}
  bucket-name: ${MINIO_BUCKET:fafa}

# Python AI 服务
fafa:
  ai-service:
    base-url: ${AI_SERVICE_URL:http://localhost:8000}
```

### 2.3 新增功能模块

#### ✅ 健康检查接口

**文件**：`HealthController.java`

```java
@GetMapping("/health")
public Result<Map<String, Object>> health() {
    Map<String, Object> data = new HashMap<>();
    data.put("status", "ok");
    data.put("service", applicationName);
    data.put("timestamp", LocalDateTime.now());
    return Result.success(data);
}
```

**测试**：
```bash
curl http://localhost:8080/api/health
```

#### ✅ OSS 文件上传服务

**文件**：`OssService.java`

**核心功能**：
- 文件上传（自动生成路径：`folder/yyyyMM/uuid.ext`）
- 流上传
- 文件删除
- 获取临时访问 URL（7天有效）
- 自动创建 Bucket

**使用示例**：
```java
@Autowired
private OssService ossService;

// 上传宠物头像
String avatarUrl = ossService.uploadFile(file, "pets/avatars");
```

**使用示例**：
```java

// 检查 Python 服务健康状态
```

### 3.3 新增功能模块

#### ✅ 通义千问 API 客户端

**文件**：`dashscope_client.py`

**核心功能**：
- 文本生成：`call_qwen_text(prompt)`
- 视觉理解：`call_qwen_vision(image_url, prompt)`
- Embedding 生成：`generate_embedding(text)`

**使用示例**：
```python
from app.core.dashscope_client import call_qwen_text, call_qwen_vision

# 文本生成
response = await call_qwen_text("你好，介绍一下自己")

# 视觉理解
result = await call_qwen_vision(
    "https://example.com/pet.jpg",
    "请描述这张宠物照片"
)
```

#### ✅ Qdrant 向量数据库客户端

**文件**：`qdrant.py`

**核心功能**：
- 初始化集合：`init_qdrant()`
- 获取客户端：`get_qdrant_client()`

**集合配置**：
- 集合名称：`fafa_photos`
- 向量维度：1536（text-embedding-v2）
- 距离度量：Cosine

**使用示例**：
```python
from app.core.qdrant import get_qdrant_client

client = get_qdrant_client()
# 执行向量搜索
results = client.search(
    collection_name="fafa_photos",
    query_vector=embedding,
    limit=10
)
```

#### ✅ MySQL 数据库连接

**文件**：`database.py`

**核心功能**：
- 同步引擎（pymysql）
- 异步引擎（aiomysql）
- 会话管理：`get_db()`
- 数据库初始化：`init_db()`

**使用示例**：
```python
from app.core.database import get_db

async def query_pet(pet_id: int):
    async with get_db() as db:
        result = await db.execute("SELECT * FROM pet WHERE id = %s", (pet_id,))
        return result.fetchone()
```
