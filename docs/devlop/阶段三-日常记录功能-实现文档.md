## 4. 应用服务实现

### 4.1 喂食记录服务 (FeedRecordApplicationService)

#### 核心功能
1. **创建喂食记录**: `createFeedRecord`
   - 验证宠物归属权限
   - 创建记录

2. **快捷喂食**: `quickFeed`
   - 复制最近一次喂食记录
   - 更新为当前时间
   - 适用于日常重复喂食场景

3. **查询记录列表**: `listFeedRecords`
   - 支持日期范围筛选
   - 按时间倒序排列

4. **更新记录**: `updateFeedRecord`
   - 权限验证
   - 更新所有字段

5. **删除记录**: `deleteFeedRecord`
   - 权限验证
   - 物理删除

6. **统计次数**: `countFeedRecords`
   - 统计日期范围内的喂食次数

#### 关键代码片段
```java
@Transactional
public Long quickFeed(Long userId, Long petId) {
    // 1. 获取最近一次喂食记录
    Optional<FeedRecord> latestOpt = feedRecordRepository.findLatestByPetId(petId);
    if (latestOpt.isEmpty()) {
        throw new BusinessException("没有历史喂食记录，请使用完整记录");
    }
    
    // 2. 复制数据，更新时间
    FeedRecord latest = latestOpt.get();
    FeedRecord newRecord = FeedRecord.builder()
            .petId(petId)
            .userId(userId)
            .feedTime(LocalDateTime.now())
            .foodName(latest.getFoodName())
            .foodType(latest.getFoodType())
            .amount(latest.getAmount())
            .unit(latest.getUnit())
            .brand(latest.getBrand())
            .build();
    
    return feedRecordRepository.save(newRecord).getRecordId().getValue();
}
```

### 4.2 体重记录服务 (WeightRecordApplicationService)

#### 核心功能
1. **创建体重记录**: `createWeightRecord`
   - 验证宠物归属权限
   - 检查当天是否已有记录（防重复）
   - 创建记录
   - **自动更新宠物表的 weight 字段**

2. **查询记录列表**: `listWeightRecords`
   - 支持日期范围筛选
   - 按日期倒序排列

3. **更新记录**: `updateWeightRecord`
   - 权限验证
   - 检查新日期是否已有记录
   - 如果是最新记录，更新宠物当前体重

4. **删除记录**: `deleteWeightRecord`

5. **趋势分析**: `getWeightTrend`
   - 计算趋势：increasing / decreasing / stable
   - 阈值：0.2kg
   - 生成趋势描述消息
   - 返回数据点列表、最大值、最小值、当前值

#### 关键代码片段
```java
@Transactional
public Long createWeightRecord(Long userId, CreateWeightRecordRequest request) {
    // 1. 验证宠物归属
    Pet pet = petRepository.findById(request.getPetId())
            .orElseThrow(() -> new BusinessException("宠物不存在"));
    
    if (!pet.getUserId().equals(userId)) {
        throw new BusinessException("无权操作该宠物");
    }
    
    // 2. 检查当天是否已有记录
    LocalDate recordDate = request.getRecordDate();
    Optional<WeightRecord> existingOpt = weightRecordRepository
            .findByPetIdAndDate(request.getPetId(), recordDate);
    if (existingOpt.isPresent()) {
        throw new BusinessException("当天已有体重记录，请编辑或删除后重试");
    }
    
    // 3. 创建记录
    WeightRecord weightRecord = WeightRecord.create(
            request.getPetId(), userId, recordDate, request.getWeight());
    weightRecord.setBcsScore(request.getBcsScore());
    weightRecord.setRemarks(request.getRemarks());
    
    WeightRecord savedRecord = weightRecordRepository.save(weightRecord);
    
    // 4. 更新宠物当前体重
    pet.updateWeight(request.getWeight().doubleValue());
    petRepository.save(pet);
    
    return savedRecord.getRecordId().getValue();
}
```

### 8.3 体重趋势计算

```java
private String calculateTrend(List<WeightRecord> records) {
    if (records.size() < 2) {
        return "stable";
    }
    
    BigDecimal latestWeight = records.get(0).getWeight();
    BigDecimal earliestWeight = records.get(records.size() - 1).getWeight();
    BigDecimal diff = latestWeight.subtract(earliestWeight);
    
    // 阈值：0.2kg
    if (diff.compareTo(new BigDecimal("0.2")) > 0) {
        return "increasing";
    } else if (diff.compareTo(new BigDecimal("-0.2")) < 0) {
        return "decreasing";
    } else {
        return "stable";
    }
}
```

## 9. 技术要点

### 9.1 日期时间处理

- **体重记录**: 使用 `LocalDate`，因为每天只记录一次
- **其他记录**: 使用 `LocalDateTime`，记录具体时间点

### 9.2 数据类型选择

- **体重**: `BigDecimal(6,2)` - 精确小数运算
- **饮水量**: `INT` - 整数毫升
- **体况评分**: `TINYINT` - 1-9 的小整数

### 9.3 索引设计

每个记录表都有：
- `pet_id` 索引 - 按宠物查询
- 时间字段索引 - 日期范围查询
- 体重记录特有：`(pet_id, record_date)` 唯一索引

### 9.4 MyBatis-Plus vs 自定义 SQL

- **基础 CRUD**: 使用 MyBatis-Plus 的 `BaseMapper`
- **复杂统计**: 使用自定义 SQL Mapper XML
