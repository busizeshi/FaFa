## 🎯 接下来需要做的

### 必须配置（启动前）

1. **获取并配置通义千问 API Key**
   ```bash
   # 编辑配置文件
   notepad .env
   notepad fafa-python\.env
   
   # 填入
   DASHSCOPE_API_KEY=sk-your_api_key_here
   ```

2. **初始化数据库**
   - 启动 MySQL 容器
   - 执行建表 SQL（从 `docs/数据库设计.md`）

3. **创建 MinIO Bucket**
   - 访问 http://localhost:9001
   - 创建名为 `fafa` 的 Bucket

### 可选配置（需要时）

4. **配置微信小程序**（需要登录功能时）
   ```ini
   WECHAT_APPID=wx1234567890abcdef
   WECHAT_SECRET=abcdef1234567890
   ```

5. **创建 RocketMQ Topics**（自动创建，或手动）
   - 访问 http://localhost:8080 (RocketMQ Dashboard)
   - 创建 `photo-analysis` 和 `report-generation`
