# 技术架构与实现方案（个人开发版）

## 一、整体架构

### 1.1 架构设计原则

- **简单实用**：单体架构，双服务模式（Java + Python）
- **职责分离**：Java 处理业务逻辑，Python 专注 AI 能力
- **容器化部署**：Docker 部署，简单高效
- **成本可控**：使用阿里云 Qwen 系列模型，性价比高

## 四、LangGraph Agent 设计

### 4.1 Agent 工具定义

```python
from langchain.tools import tool
from typing import List, Dict
import httpx

@tool
async def get_pet_profile(pet_id: str) -> Dict:
    """获取宠物基础档案信息"""
    async with httpx.AsyncClient() as client:
        response = await client.get(
            f"{settings.java_service_url}/api/pets/{pet_id}"
        )
        return response.json()

@tool
async def get_weight_history(pet_id: str, days: int = 30) -> List[Dict]:
    """获取宠物体重历史记录"""
    async with httpx.AsyncClient() as client:
        response = await client.get(
            f"{settings.java_service_url}/api/records/weight",
            params={"petId": pet_id, "days": days}
        )
        return response.json()

@tool
async def get_feeding_history(pet_id: str, days: int = 30) -> List[Dict]:
    """获取宠物喂食历史记录"""
    async with httpx.AsyncClient() as client:
        response = await client.get(
            f"{settings.java_service_url}/api/records/feeding",
            params={"petId": pet_id, "days": days}
        )
        return response.json()

@tool
async def search_photos(pet_id: str, query: str, limit: int = 10) -> List[Dict]:
    """语义搜索宠物照片"""
    # 向量化 query
    query_embedding = await embedding_service.embed(query)
    
    # Qdrant 搜索
    results = await qdrant_client.search(
        collection_name="pet_photos",
        query_vector=query_embedding,
        query_filter={
            "must": [{"key": "pet_id", "match": {"value": pet_id}}]
        },
        limit=limit
    )
    
    return [
        {
            "photo_id": r.id,
            "score": r.score,
            "description": r.payload['description'],
            "url": r.payload.get('url')
        }
        for r in results
    ]
```

### 4.2 Agent 工作流（LangGraph）

```python
from langgraph.graph import StateGraph, END
from langchain_community.chat_models import ChatTongyi
from typing import TypedDict, Annotated
import operator

class AgentState(TypedDict):
    messages: Annotated[list, operator.add]
    pet_id: str
    data: dict

# 初始化 LLM
llm = ChatTongyi(
    model="qwen-plus",
    dashscope_api_key=settings.dashscope_api_key
)

# 绑定工具
llm_with_tools = llm.bind_tools([
    get_pet_profile,
    get_weight_history,
    get_feeding_history,
    search_photos
])

def call_model(state: AgentState):
    """调用 LLM"""
    response = llm_with_tools.invoke(state['messages'])
    return {"messages": [response]}

def should_continue(state: AgentState):
    """判断是否需要调用工具"""
    last_message = state['messages'][-1]
    if last_message.tool_calls:
        return "tools"
    return END

def call_tools(state: AgentState):
    """执行工具调用"""
    last_message = state['messages'][-1]
    results = []
    
    for tool_call in last_message.tool_calls:
        tool_name = tool_call['name']
        tool_args = tool_call['args']
        
        # 注入 pet_id
        if 'pet_id' in tool_args and not tool_args['pet_id']:
            tool_args['pet_id'] = state['pet_id']
        
        # 执行工具
        tool_result = await globals()[tool_name].ainvoke(tool_args)
        results.append({
            "tool_call_id": tool_call['id'],
            "output": tool_result
        })
    
    return {"messages": results}

# 构建图
workflow = StateGraph(AgentState)
workflow.add_node("agent", call_model)
workflow.add_node("tools", call_tools)
workflow.set_entry_point("agent")
workflow.add_conditional_edges("agent", should_continue, {
    "tools": "tools",
    END: END
})
workflow.add_edge("tools", "agent")

agent = workflow.compile()
```

### 4.3 API 接口

```python
from fastapi import FastAPI, WebSocket
from pydantic import BaseModel

app = FastAPI()

class ChatRequest(BaseModel):
    user_id: str
    pet_id: str
    message: str
    session_id: str = None

@app.post("/api/chat")
async def chat(request: ChatRequest):
    """AI 对话接口"""
    # 获取历史对话
    history = await get_conversation_history(request.session_id)
    
    # 构建状态
    state = {
        "messages": history + [("human", request.message)],
        "pet_id": request.pet_id,
        "data": {}
    }
    
    # 执行 Agent
    result = await agent.ainvoke(state)
    
    # 获取最终回答
    answer = result['messages'][-1].content
    
    # 保存对话历史
    await save_conversation(request.session_id, request.message, answer)
    
    return {"answer": answer}

@app.websocket("/ws/chat")
async def chat_websocket(websocket: WebSocket):
    """WebSocket 实时对话（流式输出）"""
    await websocket.accept()
    
    while True:
        data = await websocket.receive_json()
        
        async for chunk in agent.astream(data):
            await websocket.send_json(chunk)
```

## 八、成本估算

### 8.1 阿里云 AI 成本

**qwen-turbo**（日常对话）
- ¥0.003 / 1K tokens
- 假设日均 1000 次对话，平均 500 tokens
- 月成本：1000 × 30 × 0.5 × 0.003 = ¥45

**qwen-plus**（报告生成）
- ¥0.02 / 1K tokens
- 假设月均 1000 份报告，平均 2K tokens
- 月成本：1000 × 2 × 0.02 = ¥40

**qwen-vl-plus**（图片理解）
- ¥0.018 / 1K tokens（图片 + 文本）
- 假设日均 500 张照片
- 月成本：500 × 30 × 0.018 ≈ ¥270

**text-embedding-v2**（向量化）
- ¥0.0007 / 1K tokens
- 假设日均 500 次向量化，平均 100 tokens
- 月成本：500 × 30 × 0.1 × 0.0007 ≈ ¥1

**总计：约 ¥350/月**（1000 日活用户）
