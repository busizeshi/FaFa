## 一、市场全景：从「养得多」到「养得好」

### 1.1 核心数据（2026 中国宠物行业白皮书）

| 指标 | 数值 | 同比 |
|------|------|------|
| 城镇犬猫消费市场规模 | 3126 亿元 | +4.1% |
| 城镇犬猫总量 | 1.26 亿只 | +1.8% |
| 其中犬 / 猫 | 5343 万 / 7289 万只 | +1.6% / +1.9% |
| 单犬年均消费 | 3006 元 | +1.5% |
| 单猫年均消费 | 2085 元 | +3.2% |
| 犬消费市场 | 1606 亿元 | +3.2% |
| 猫消费市场 | 1520 亿元 | +5.2% |

> 来源：《2026 年中国宠物行业白皮书（消费报告）》，派读宠物行业大数据平台出品

**关键判断**：数量增速仅 1.8%，但单宠消费持续创新高——行业已从「增量扩张」全面转向「存量深耕」。这意味着**工具型产品的机会不在拉新宠主，而在帮现有宠主把宠物养得更好、更省心**。

### 1.2 消费结构

| 品类 | 份额 | 备注 |
|------|------|------|
| 食品 | 53.7% | 主粮/零食/营养品，鲜食化趋势明显 |
| 医疗 | 27.6%（约 863 亿） | 体检品类逆势增长，诊疗略有回落 |
| 用品 | 12.2% | 细分赛道扩容 |
| 服务 | 6.5% | 挖掘空间最大 |

### 1.3 人群画像

- **90 后占 42.7%，00 后占 26.3%**——年轻群体合计近七成，彻底主导市场
- 年轻宠主把宠物视为「家庭成员」而非工具，愿意为情绪价值和科学养护支付溢价
- 72% 城镇养宠主为职场上班族，工作日日均陪伴不足 3.5 小时（艾瑞咨询 2025）

**对产品的启示**：目标用户是年轻、忙碌、把宠物当家人的上班族。他们需要的不是「更多功能」，而是**更低成本的记录 + 更主动的健康守护 + 更省心的日常管理**。

## 二、用户核心痛点

### 2.1 医疗信息不对称（最痛）

- 宠物医疗收费不透明，同一检查在不同医院收费相差数倍（新华社 2025.06 调查）
- 「感觉宠物看病像开盲盒」——宠主难以判断诊疗必要性和收费合理性
- 过度医疗、误诊、资质不全等问题频发，黑猫投诉平台宠物医院投诉量一年增长 67%
- **宠物疾病早期确诊率不足 28%，超六成疾病因发现不及时错过最佳干预窗口**

> 来源：新华每日电讯《同样检查收费差几倍 宠物医疗为何频现"糊涂账"》2025.06；央视网《宠物经济消费调查报告》2025.09

**产品机会**：FaFa 的「数据→AI 分析→异常预警」闭环，恰好能在「就医前」帮宠主建立数据化的健康基线，让宠主带着结构化病史去医院，而不是空手描述「它好像不太对劲」。

### 2.2 食品安全焦虑

- 48.85% 受访者认为宠物食品核心痛点是「质量不稳定」（江苏消保委 2025）
- 39.45% 反馈宠物食用后食欲减退，30.29% 出现毛发问题，27.27% 皮肤过敏
- 「配料表前两位写鲜鸡肉，实际是鸡肉粉」的虚假宣传屡见不鲜

**产品机会**：食品管理卡 + AI 包装识别已有设计，可进一步做「成分安全评分」和「换粮过渡记录」。

### 2.3 日常照护的「遗忘焦虑」

- 疫苗、驱虫、体检等周期性事项容易遗忘
- 多宠家庭信息混乱（谁喂了哪只、哪只该驱虫了）
- 家庭成员间信息不同步（「你喂狗了吗？」）

### 2.4 就医时的「信息断层」

- 纸质病历、检查报告散落各处，换医院时无法完整交接
- 宠主到院后想不起「它到底哪天开始不吃」「上次用的什么药」
- 医生拿不到连续的健康数据，只能重复检查

| 功能模块 | 代表产品 | FaFa 现状 |
|----------|----------|-----------|
| 宠物档案 + 多宠管理 | 全部竞品 | ✅ 已有 |
| 日常记录（喂食/体重/排便） | 全部竞品 | ✅ 已有（正在重构为打卡模式） |
| 疫苗/驱虫/体检提醒 | 宠护、PetPals、宠胖胖 | ✅ 已有提醒系统 |

| 成长时间轴 | 宠物记、Soulkin | ✅ 已有 |
| 照片 AI 搜索 | — | ✅ 已有（差异化优势） |
| AI 报告/内容创作 | — | ✅ 已有设计（差异化优势） |
| 宠物社交/社区 | 宠胖胖、宠物记 | 🚫 明确不做 |
| 智能硬件联动 | Catlink、佩优优 | 🚫 明确不做 |
| 宠物交易/领养 | 买只宠物 | 🚫 明确不做 |
| 寄养/上门服务 | 宠胖胖 | 🚫 不做（涉及社交/服务撮合） |

### 关键发现

**FaFa 的差异化优势**（竞品几乎没有）：
- 照片/视频 AI 语义搜索（qwen3-vl-embedding）
- 宠物个体识别（三视图向量匹配）
- AI 驱动的周期报告和内容创作
- 每日状态打卡 + 健康预警引擎

**FaFa 的明显缺口**（竞品已验证、用户强需求）：
- 就医档案
- 用药管理
- 养宠记账
- 家庭协同
- 病历扫描结构化

## 四、功能拓展建议

按「用户价值 × 实现成本 × 与现有架构契合度」排序，分为三个梯队。

### 第一梯队：高价值 + 低成本 + 强契合（建议优先做）

#### 4.1 就医档案

**痛点**：宠物看病贵且不透明，宠主需要完整病史来避免重复检查、辅助医生判断。

**功能设计**：
- 每次就诊记录：医院、医生、日期、主诉、诊断、处方、费用、票据照片
- 与现有「事件记录」打通——就诊本身就是一种事件，但增加医疗专属字段
- 疫苗/驱虫记录自动归入就医档案时间线
- AI 辅助：上传检查报告照片 → OCR + LLM 提取结构化指标（血常规、生化等）
- **就诊摘要一键导出**：就医前生成「近 N 天症状时间线 + 历史诊断 + 用药记录」，可复制/生成图片带给医生

**与现有架构的关系**：
- 复用事件记录（event_record）表结构，增加 `medical` 类型和专属字段
- 票据照片复用现有 OSS + 照片上传链路
- 报告 OCR 复用 Python 侧 qwen-vl 能力
- 就诊摘要复用 AI 助手的数据查询工具链

**为什么优先**：这是「数据→AI→用户获益」闭环中最直接兑现价值的场景。宠主带着一份结构化病史去医院，立刻能感受到「记录了一年数据」的回报。

#### 4.2 用药管理

**痛点**：慢性病（肾病、糖尿病、皮肤病）需要长期用药，宠主容易漏喂、重喂、记错剂量。

**功能设计**：
- 药品档案：名称、规格、用途、开始日期、疗程
- 用药计划：每日几次、每次剂量、饭前/饭后
- 用药提醒：接入现有提醒系统
- 用药记录：每次实际用药打卡（可合并到每日打卡）
- 与就医档案关联：处方 → 自动生成用药计划

**与现有架构的关系**：
- 提醒系统（reminder）已有完整 CRUD + 定时任务，直接复用
- 用药打卡可作为「照护动作」类记录的一种

#### 4.3 养宠记账

**痛点**：单犬年均消费 3006 元、单猫 2085 元，但多数宠主对钱花在哪没有概念。宠物保险理赔、年度总结都需要费用数据。

**功能设计**：
- 支出分类：食品 / 医疗 / 用品 / 美容 / 保险 / 其他
- 快速记账：金额 + 分类 + 备注（可选照片），≤3 秒完成
- 月度/年度统计：分类饼图 + 趋势折线
- 与就医档案联动：就诊费用自动归入医疗支出
- 与食品管理联动：食品购买记录可关联价格
- AI 年报素材：「今年你在豆包身上花了 XX 元，其中医疗占 XX%」

**与现有架构的关系**：
- 新增 expense_record 表，结构简单
- 统计接口复用现有统计模式
- AI 报告直接消费记账数据

**为什么优先**：实现成本极低（一张表 + CRUD + 统计），但用户感知强——年底看到「今年花了多少钱养猫」的情绪价值很高，且为 AI 年报提供关键数据维度。

### 第二梯队：高价值 + 中等成本（建议第二批做）

#### 4.4 家庭协同（多人共管）

**痛点**：多宠家庭、情侣/夫妻共养、请人代喂等场景下，「谁喂了」「谁该驱虫了」信息不同步。Soulkin 和 PetVault 都以此为核心卖点。

**功能设计**：
- 宠物空间邀请：生成邀请码/链接，家人扫码加入
- 角色权限：主人（全部权限）/ 成员（记录+查看）/ 临时照护者（限时查看+记录）
- 操作留痕：每条记录标注「谁记的」，避免重复喂食
- 提醒共享：驱虫/疫苗提醒推送给所有成员
- 临时授权：出差时给宠物店/朋友开限时权限

**与现有架构的关系**：
- 需要新增 pet_member 关联表（pet_id, user_id, role）
- 现有 Sa-Token 鉴权体系可扩展
- 记录表增加 operator_id 字段
- 这是**架构改动最大**的功能，需要仔细设计权限模型

**注意**：这不是「社交」——没有公开动态、没有评论点赞、没有陌生人发现。纯粹是**私密家庭协作工具**，类似共享日历/共享备忘录。

#### 4.5 病历/报告扫描结构化

**痛点**：纸质疫苗本、检查报告、处方单散落各处，换医院时无法完整交接。

**功能设计**：
- 拍照上传 → AI OCR 提取结构化信息（疫苗名称/日期、检查指标、药品/剂量）
- 用户确认后存入就医档案
- 支持：疫苗本、血常规/生化报告、B超/X光报告、处方单、发票
- 历史病历补录：把以前的纸质记录逐步数字化

**与现有架构的关系**：
- 复用 Python 侧 qwen-vl 视觉理解能力
- 复用照片上传 → MQ → Python 处理的异步链路
- 结构化结果写入就医档案

#### 4.6 食品安全评分（增强现有食品管理）

**痛点**：宠主面对成分表无从判断，虚假宣传泛滥。

**功能设计**（在现有食品管理卡基础上增强）：
- AI 解析成分表后，增加「安全评分」维度：
  - 蛋白质来源是否清晰（鲜肉 vs 肉粉）
  - 是否含争议添加剂（BHA/BHT/人工色素）
  - 钙磷比是否合理
  - 与宠物年龄/品种的适配度
- 换粮过渡记录：新旧粮比例、过渡天数、宠物反应（软便/拒食/正常）
- 食品对比：两张食品卡并排对比营养成分

**与现有架构的关系**：
- 食品管理卡已有设计，增加评分字段和对比视图
- AI 解析复用现有包装识别链路

### 第三梯队：中长期储备

#### 4.7 健康基线与品种参考

- 体重不仅记录绝对值，还对比品种标准范围（「豆包 5.2kg，英短公猫标准范围 4.5-7.0kg，处于健康区间」）
- 需要积累品种数据，初期可用公开数据源

#### 4.8 生命周期阶段化服务

- 幼宠期（0-1 岁）：疫苗密集期提醒、体重增长曲线对比、社会化训练建议
- 成年期（1-7 岁）：年度体检提醒、体重管理、口腔护理
- 老年期（7 岁+）：半年体检提醒、关节/肾脏/甲状腺关注点、饮食调整建议
- 让提醒系统从「闹钟」进化为「养宠知识库」

#### 4.9 宠物保险辅助

- 不做保险销售（避免合规风险），但可以做：
  - 就医费用记录 → 保险理赔材料整理
  - 保单到期提醒
  - 理赔材料清单生成（基于就医档案）

#### 4.10 应急信息卡

- 一键生成宠物应急信息卡：品种、血型（如有）、过敏史、慢性病、紧急联系人、常去医院
- 可生成图片保存到手机，紧急时出示
- 成本极低，情绪价值高

## 五、明确不做的功能（红线）

| 功能 | 不做原因 |
|------|----------|
| 社区/广场/动态/评论/点赞/关注 | 产品定位明确排除，合规成本高 |
| 私信/群聊/附近宠友 | 同上 |
| 商城/电商/二手交易 | 非核心能力，运营成本高 |
| 在线问诊/AI 诊断/处方建议 | 医疗合规红线，产品边界是「数据分析」不是「医疗诊断」 |
| 智能硬件/IoT 联动 | 明确排除 |
| 宠物交易/领养/配种 | 非产品方向 |
| 寄养/上门服务撮合 | 涉及服务交易和社交属性 |
| 自动发布社交媒体内容 | 只生成内容，不负责发布 |

## 六、优先级总览与落地节奏建议

```
第一批（与打卡系统同期或紧随其后）
├── 就医档案          ← 数据闭环价值最高的场景
├── 用药管理          ← 复用提醒系统，成本低
└── 养宠记账          ← 一张表 + CRUD，情绪价值高

第二批（AI Agent 落地后）
├── 就诊摘要导出      ← 依赖 AI 数据查询能力
├── 病历扫描结构化    ← 依赖 qwen-vl OCR
└── 食品安全评分      ← 增强现有食品管理

第三批（用户量起来后）
├── 家庭协同          ← 架构改动大，需要用户基数支撑
├── 生命周期阶段化    ← 需要品种数据积累
└── 应急信息卡        ← 成本极低，可随时插入
```

## 七、核心结论

1. **市场已从「增量」转向「存量深耕」**——工具型产品的竞争力不在功能数量，而在「帮宠主把已有的宠物养得更好」。FaFa 的「记录→数据→AI→价值」闭环方向正确。

2. **医疗信息不对称是最大痛点**——就医档案 + 就诊摘要导出是最能兑现「数据价值」的功能，建议第一批做。

3. **记账和用药是低成本高感知的补充**——实现简单，但补全了「养宠全生命周期管理」的拼图。

4. **家庭协同是架构级功能**——价值确定但改动大，建议在核心功能稳定后再做。

5. **FaFa 真正的护城河不在「记录」而在「AI 理解」**——照片语义搜索、个体识别、健康趋势预警、AI 报告，这些是竞品（宠护、PetPals 等纯工具型产品）做不到的。功能拓展应始终围绕「让 AI 更懂这只宠物」展开，而不是堆砌记录表单。
