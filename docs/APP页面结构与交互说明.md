# FaFa 日记｜APP 页面结构与交互说明

> **文档用途：** Android 与 iOS 共用的页面清单、信息结构和交互路径  
> **依据：**《项目初步设计.md》修订版  
> **本次范围：** 只定义有哪些页面、页面信息、操作、状态和流转；不涉及配色、字体、图标、动效或视觉风格。  
> **覆盖范围：** P0 首发、P1 AI 与协作、P2 社区及可选创作。需要额外服务或运营能力的功能会单独标明。

## 一、设计目标与全局约定

### 1. 目标

任何页面都应让用户清楚知道当前宠物、数据来源、保存结果和下一步去向。主人填写、实际测量、AI 识别待确认、AI 生成内容必须区分。用户遇到空数据、拒绝权限、断网、AI 失败或上传失败时，仍能返回可用的手动流程。

首要任务控制为不超过三段主要操作页；权限说明、系统授权弹窗和操作确认不算主要步骤，但必须有取消和返回路径。

### 2. 页面类型

- **主页面：** 首页、记录、相册、AI 助手、我的；带主导航。
- **详情页：** 从列表或卡片进入，返回原位置。
- **表单页：** 新建、编辑、搜索条件和报告设置；离开前处理未保存内容。
- **弹层/底部面板：** 快速记录、宠物切换、筛选、删除确认等短操作；关闭后回到触发它的页面。
- **系统页面：** 邮件、系统照片选择器、系统通知权限、系统分享面板；取消后回到调用页。
- **状态页：** 空数据、加载、网络失败、权限拒绝、审核中等；必须给出下一步操作。

### 3. 全局导航和页面栈

主导航固定为：**首页、记录、相册、AI 助手、我的**。

- 当前宠物在首页、记录、相册、AI 助手间保持一致；切换后当前列表、提醒、搜索范围和新建目标一起切换。
- 表单中切换宠物前，先提示当前内容属于哪只宠物；未保存内容不得悄悄换目标。
- 从通知、分享链接或报告深链接进入时，登录后恢复原目标。对象已删除、归档或无权访问时说明原因并可返回来源。
- 保存记录后进入记录详情；从快速记录进入时还可以“继续记录”或“回首页”，但不能丢掉保存结果。
- 系统返回键与页内返回一致。表单未改动直接返回；有改动时选择“保存草稿并退出、放弃更改、继续编辑”。
- 所有重要列表有加载、首次空、筛选无结果、加载失败、重试和继续加载状态。
- 权限拒绝时不循环请求授权，并保留不依赖该权限的使用路径。

## 二、全局导航树

- **启动与账号**
  - 启动路由
  - 欢迎/条款说明
  - 登录、注册、邮箱验证、忘记密码、重置密码
  - 添加第一只宠物（允许跳过）
  - 邀请链接登录/注册并接受协作邀请
- **首页**
  - 宠物切换
  - 今日待办 → 提醒详情、完成/延期/跳过
  - 快速记录 → 类型 → 表单 → 记录详情
  - 指标卡 → 趋势 → 对应记录
  - 最近动态 → 记录详情或素材详情
- **记录**
  - 时间线 → 搜索/筛选 → 记录详情 → 编辑/删除/附件
  - 喂食计划 → 新建/详情/编辑/暂停
  - 食品档案 → 手工新增/包装识别/核对/详情
  - 提醒日历 → 日期详情/提醒详情/新增
  - 周报月报 → 设置范围/生成/编辑/来源核对/分享
- **相册**
  - 相册 → 上传/筛选/搜索 → 结果 → 素材详情 → 编辑关联/删除/加入报告
- **AI 助手**
  - 助手首页/历史会话 → 对话 → 来源资料/待确认操作/结果
  - 隐私与会话管理
- **我的**
  - 个人资料、宠物管理、家庭协作、照护清单
  - 提醒偏好、隐私与 AI 数据、系统权限
  - 账号安全、资料复制/导出、注销、帮助与协议
- **P2 宠物圈子**
  - 关注/最新内容流、搜索、公开主页、帖子详情、评论
  - 发布/预览/审核状态、互动通知、收藏
  - 举报、屏蔽、内容管理、申诉
- **P2 可选形象与创作**
  - 3D 形象说明/图片提交/生成状态/预览与删除
  - AI 图文或视频创作/选择素材/确认/生成状态/编辑/分享

## 三、启动、登录与新手流程（P0）

### A01 启动路由页

**显示：** 应用启动状态。  
**规则：** 已登录到最近访问页面；首次使用但无宠物到首页空状态；未登录到欢迎/登录；过期登录成功后返回原目标；维护状态可重试，不能丢失本地草稿。

### A02 欢迎与条款页

**信息：** 产品用途、用户协议、隐私政策、AI 功能说明入口。  
**操作：** 登录、注册、查看协议。必要协议不得预勾选；浏览协议后返回本页。

### A03 登录页

**字段：** 邮箱、密码。  
**操作：** 登录、显示/隐藏密码、忘记密码、去注册。  
**状态：** 邮箱格式/密码为空、密码错误、网络失败、账号受限；登录成功恢复深链接目标或打开首页，失败不清除邮箱。

### A04 注册页

**字段：** 邮箱、密码、确认密码、必要协议同意。  
**操作：** 发送验证邮件、去登录、查看协议。  
**校验：** 邮箱格式、密码规则、重复密码一致；邮箱已注册时可直接登录或重置密码。

### A05 邮箱验证页

**信息：** 部分遮蔽的目标邮箱、发送状态、重发倒计时。  
**操作：** 已完成验证、重发、修改邮箱、返回注册。  
**状态：** 邮件未到、发送失败、验证码过期；邮件链接返回应用后接续原流程。

### A06 忘记密码页

输入邮箱并发送重置邮件。提交后统一提示，不泄露邮箱是否注册；发送失败可重试。

### A07 重置密码页

输入新密码及确认密码；验证链接过期/已使用时重新申请。成功后回登录页并提示使用新密码登录。

### A08 首次添加宠物页

昵称和猫/狗必填；头像、生日/估算年龄、到家日期可选。单页完成最小资料，允许跳过；保存成功设为当前宠物。

### A09 无宠物空状态

首页提供添加宠物入口；记录、相册、AI 助手各有自己的无宠物提示和添加入口，不显示无法操作的空页面。

### A10 邀请接受路由页（P1）

显示邀请人、宠物、权限和有效期；登录/注册后接受或拒绝。已过期/撤销/已接受时说明状态并提供返回或联系邀请人。

## 四、宠物档案页面（P0）

### B01 宠物切换面板

显示头像、昵称、猫/狗和当前选择；活跃/归档分组。操作：切换、添加、管理。切换后刷新当前页数据；有未保存表单时询问保存/放弃/取消切换。

### B02 宠物管理列表

显示活跃宠物和归档入口；操作：新增、查看、设为当前、归档、恢复、删除。空列表引导新增。

### B03 宠物档案详情

显示头像、昵称、物种、生日/估算年龄、到家时间、品种、绝育状态、备注、最近体重、照护成员。操作：编辑、时间线、计划、提醒、设为当前、归档。体重卡进入趋势，成员卡进入权限页；缺项显示未填写。

### B04 新增/编辑宠物表单

字段：昵称、猫/狗、头像、生日或估算年龄、到家日期、品种、性别、绝育状态、备注。生日未知可不填；未来日期需确认。首版不要求三视图，不承诺照片生成准确 3D 或身份识别。

### B05 头像选择流程

系统照片选择器 → 预览/确认 → 保存。用户取消、照片权限拒绝、文件不支持或读取失败时可返回并不设置头像；提供系统设置入口。

### B06 归档宠物列表

显示归档日期；可查看历史档案、恢复、永久删除。归档资料只读；恢复后回活跃列表，需主人手动设为当前宠物。

### B07 归档/恢复/删除确认

说明关联记录、素材、成员和公开帖子的影响。永久删除前要求处理有效分享/协作，清理素材文件、业务数据和向量，不留下悬空入口。

## 五、首页和快速记录（P0）

### C01 首页

**信息：** 当前宠物切换、日期、宠物照片、今日待办摘要、快速记录、最近记录/素材、已有连续指标趋势、可关闭的 AI 今日整理。  
**跳转：** 待办到详情/列表；指标到趋势；动态到详情；快捷按钮到记录类型。  
**空状态：** 无宠物、无记录、无提醒、无相册内容分别处理。AI 总结只复述已有记录，不把没记录说成异常。

### C02 快速记录类型面板

类型：喂食、饮水、体重、疫苗、驱虫、用药、就医、洗护、日常观察、纪念/成长、文字记录。面板显示当前宠物并允许切换；选类型后进表单，取消回原页面。

### C03 首页待办列表

分今天、未来、逾期、已完成；支持按宠物/类型筛选。可以完成、延期、跳过、暂停、查看详情或新增。逾期不静默消失；空列表可创建自定义提醒。

### C04 指标趋势页

支持体重、实际喂食量、实测饮水量等；显示单位、时间范围、测量来源和数据点，点击数据点进原记录。少于两个数据点时显示原始值和新增记录入口；主观饮水等级不换算成数值。

## 六、记录与时间线（P0/P1）

### D01 记录主页/时间线

当前宠物、按日期分组的记录、类别筛选、搜索、新建按钮；入口喂食计划和提醒日历。无记录可快捷新增；筛选无结果可清空；失败可重试并保留筛选。

### D02 记录筛选

条件：宠物、事件类别、日期范围、来源（手动/AI 确认）、是否有附件。应用/清空/取消；重新打开保留最近筛选。

### D03 记录类型选择

显示已实现的事件类别、简短说明和搜索。选择类型进专用表单；未实现的类型不得作为可点击入口。

### D04 喂食记录表单

宠物、时间、食品、计划量、实际投喂量、吃完量（可选）、完成状态、备注、附件。支持按计划、复用上次、部分吃完、未吃；计划值和实际值分开保存。

### D05 饮水记录表单

宠物、时间、实测数值/单位（可选）、主观等级（少/一般/多/不清楚）、备注。两种数据分开保存，主观等级不生成精确趋势。

### D06 体重记录表单

宠物、称重时间、体重/单位、称重来源、身体状况评分（可选）、备注和照片。数值须大于零；显示统一单位和来源。

### D07 疫苗记录表单

宠物、疫苗名称、接种日期、机构/兽医、批次/证明附件、下次日期、备注。下一次提醒单独由主人确认，系统不推导周期。

### D08 驱虫记录表单

宠物、产品名称、使用日期/方式、体重引用、兽医说明、用户填写的下次日期、附件/备注。AI 不推荐产品或剂量。

### D09 用药记录表单

药品、来源（处方/主人）、用法和剂量原文、起止日期、执行时间、处方附件、备注。处方照片识别标为待核对；缺少频次时允许保存记录，但不创建剂量提醒。

### D10 洗护记录表单

项目（洗澡、梳毛、剪指甲、清洁或自定义）、日期、执行人、备注、附件、可选下次提醒。

### D11 就医记录表单

日期、机构/兽医、主人主诉、医院给出的诊断/建议原文、检查/处方附件、复诊日期、费用、备注。清楚区分主人填写与医院材料；复诊提醒须确认。

### D12 日常观察表单

日期、类别（精神/食欲/排便/皮毛/行为/其他）、主人描述、自评等级（可选）、图片/视频、备注。保存为“主人观察”，不能改写成诊断。

### D13 纪念/成长表单

类型（到家、生日、训练、旅行、纪念日、自定义）、标题、日期、文字、照片/视频、是否纳入报告。

### D14 文字随手记

宠物、时间、自由文本、附件。可普通保存或请求 AI 整理；AI 不可用时仍可保存原文。

### D15 AI 文字提取页（P1）

输入原文/附件，选择提取；保留返回修改和取消。处理中可停止；失败保留原文并可重试或手动保存。

### D16 AI 提取核对页（P1）

字段：宠物、日期、类型、数量/单位、描述、附件关联。标识已识别/需确认；允许逐项修改、删除错误字段、拆分多条记录。确认前不写正式时间线。

### D17 记录详情

显示事件、宠物、时间、值/单位、数据来源、实测/估算、附件、创建/修改时间。操作编辑、删除、查看附件、关联提醒、看趋势。AI 草稿不可混入正式记录。

### D18 记录编辑页

使用对应类型表单并预填原值；保存后保留修改来源和时间；取消按全局未保存规则处理。

### D19 删除记录确认

显示记录、宠物和日期；解释附件及关联提醒的影响。默认只删记录；有关联时让用户选择保留或同时删除提醒。

### D20 附件查看页

预览图片、视频、文档，显示文件名、上传时间和来源记录。失败可重试/返回；删附件需确认，说明记录是否仍保留。

## 七、喂食计划与食品档案（P0/P1）

### E01 喂食计划列表

当前、暂停、已结束分组；显示宠物、日期、食物和时段摘要。可新增、查看、暂停/恢复、结束；空状态可先记录食物或建计划。

### E02 创建计划：宠物与目标

选择宠物、目标（维持/增重/减重/仅记录）、体重、年龄阶段、绝育、活动水平、身体评分和特殊情况。资料缺失降低估算精度；疾病、怀孕哺乳、幼龄、特殊饮食提示先咨询兽医，也允许只建手动计划。

### E03 创建计划：食品与能量参考

选择食品、包装能量和单位、每日目标量；展示计算输入、资料来源/版本、公式和结果范围，可展开公式。缺少能量密度时只录份量，不推算热量；AI 不改计算结果。

### E04 创建计划：时间段与复核

选择每日时段、每次目标量、生效日期、结束条件和提醒开关。保存后进详情；也可只保存计划不创建提醒。三段主流程为“目标、食品、时段/复核”。

### E05 计划详情

显示宠物、周期、食品、每天/每次份量、估算依据、提醒状态和实际记录摘要。操作编辑、暂停/恢复、结束、记一次喂食、看食品详情。数据更新不得自动改旧计划。

### E06 计划编辑/暂停/结束

修改展示新旧值和生效日；暂停时选择是否暂停关联提醒；结束时选择是否保留提醒；保存前列出受影响日程。

### E07 食品档案列表

食品名称、类别、能量字段是否核对、适用宠物/常用标记；支持搜索、新增、编辑、归档、选择到计划。

### E08 新建/编辑食品

名称、类别、品牌、每单位重量、包装能量/单位、成分标签、来源照片、开始使用日期、备注；支持手工输入和拍照识别。

### E09 包装照片选择页（P1）

调用系统相机/照片选择器，告知处理用途和避免拍入个人信息；取消回食品表单，识别失败可手工填。

### E10 包装识别核对页（P1）

原图和预填字段并列核对；可修改名称、能量、单位、成分。缺失字段留空，不自动补全。逐字段确认后保存。

### E11 食品详情页

显示来源、核对状态、包装附件和引用此食品的计划；可编辑/归档。删除被现行计划引用的食品前，先改计划或选择归档。

## 八、提醒、日历和通知（P0）

### F01 提醒日历

月/周/列表切换，宠物和类型筛选，日期事项；可新建、完成、延期、跳过、看详情。空月份仍可新增，时区变化不改错日期。

### F02 提醒列表

按今天、未来、逾期、完成、跳过、暂停分组；支持过滤宠物/类型/状态和新建。

### F03 日期事项页

列出日期内提醒和相关记录；空日期可新增；点击提醒进详情，完成保留时间和状态。

### F04 提醒详情

标题、宠物、时间、重复规则、来源、关联计划/记录、通知状态；操作完成、稍后、跳过、编辑、暂停、删除。

### F05 新建/编辑提醒

标题、宠物、时间、重复周期、结束日、提前量、关联记录、备注。预览后续触发时间；结束日不得早于开始日。

### F06 重复周期选择

不重复、每天、每周、每月、自定义间隔和结束条件。月末日期规则须预览接下来几次时间，避免保存后用户不知何时提醒。

### F07 提醒处理面板

完成、稍后、跳过分别处理；延期必须选新时间，跳过可填原因。成功后首页/日历同步更新，并可短暂撤销。

### F08 提醒偏好

免打扰时间、默认提前量、类别开关、系统通知状态、时区；系统通知关闭时仍显示应用内待办和设置入口。

### F09 通知权限说明

首次创建本地提醒时说明用途，再请求系统权限。拒绝后仍能保存提醒，不重复弹窗；提供打开系统设置说明。

## 九、相册、上传和搜索（P0/P1）

### G01 相册首页

当前宠物、按日期分组的照片/视频、最近上传、标签、搜索和上传入口。无素材引导上传；权限被拒仍可浏览已有内容。

### G02 相册筛选

宠物、日期范围、照片/视频、标签、是否关联记录；应用后返回结果并显示条件，清空/取消有效。

### G03 选择上传素材

调用系统相机/照片选择器，可多选；显示文件数量/限制。取消返回相册。

### G04 上传信息确认

为素材选择宠物、日期、标签、备注和可见范围；默认私密，未确认宠物可保持未关联。

### G05 上传进度与结果

逐个展示上传中/成功/失败；失败可重试或移除；成功可继续编辑标签。离开后状态可恢复，不能假成功。

### G06 素材搜索

P0 支持关键词、宠物、日期、类型和标签；P1 增加自然语言语义搜索。示例不得暗示能认出某只宠物或诊断疾病。

### G07 搜索结果

显示匹配素材、日期、宠物和匹配条件；可改词、筛选、纠正关联。无结果给清条件/改词/按时间浏览入口。

### G08 素材详情

大图/视频、日期、宠物、标签、所属记录、上传状态、可见范围。操作编辑、移除关联、删除、纳入报告、显式分享。

### G09 素材信息编辑

修改日期、宠物、标签、备注、记录关联和可见范围。多宠物素材修改关联时确认目标。

### G10 素材删除确认

显示文件和关联记录；选择从记录移除或同时删除素材；明确不可恢复。删除时清理对象存储、元数据及向量索引。

### G11 语义索引状态（P1）

首次处理中、完成、失败或不可用状态；失败不影响普通相册和筛选，可重试或使用关键词。

## 十、AI 助手（P1）

### H01 助手首页

当前宠物、提问示例、最近会话、AI 边界和隐私入口。无记录时说明一般知识仍可问，但个人事实需要先记录。

### H02 对话页

对话内容、宠物范围、引用卡片、生成状态。操作发送、停止、重试、复制/保存、查看来源、新建/删除会话。多宠物问题必须确认对象；回答标记“根据记录整理”或“一般知识”。

### H03 来源资料页

显示回答引用的记录、日期、宠物和资料类型；点击回详情。资料已删除/无权时说明并返回对话。

### H04 AI 操作草稿核对页

用于创建/修改记录或提醒。显示操作、宠物、字段、日期和变更内容；允许修改、确认、取消。删除跳专用确认，不可由聊天内容直接删除。

### H05 AI 操作结果

成功进入详情，允许继续编辑或撤销（业务允许时）；失败显示原因、重试和手动处理入口，不能误报成功。

### H06 会话历史

按时间/宠物显示会话；搜索、继续、删除单个、清空。删除会话不删除已保存正式记录，除非用户另选明确操作。

### H07 AI 数据使用说明

说明本次会发送的资料、模型服务商、用途和保存规则；允许关闭个人记录查询、图片语义索引和历史保存，关闭后仍可手动搜索。

### H08 AI 失败/安全状态

网络错误、服务繁忙、无资料依据、问题不支持、图片失败、输入过长等；保留输入并可重试、编辑或手动保存。高风险医疗问题只建议联系动物诊疗机构。

## 十一、报告与分享（P1）

### I01 报告列表

报告周期、宠物、生成日期、草稿/已分享状态；支持新建、查看、编辑、删除。

### I02 报告范围设置

宠物、周报/月报、日期范围、数据类别、照片数量、AI 摘要开关；先预览资料数量再生成。数据不足时说明空缺，不编造。

### I03 生成状态

显示进度和取消；失败保留设置，可重试或仅用模板统计。

### I04 报告预览/编辑

统计、时间线、照片、AI 摘要、主人备注和来源卡片；可编辑摘要、删卡片、替换照片、重生成单段。

### I05 报告来源核对

逐条显示统计与摘要引用的记录；允许移除错误关联、回记录详情；源数据变化后可刷新报告。

### I06 分享范围预览

选择文字、图片、指标、宠物昵称和时间范围；展示最终内容。默认不公开，不带入未选择资料。

### I07 系统分享面板

调用系统分享。取消返回预览；成功回报告详情；不推断外部平台已发布。

### I08 报告删除确认

只删除报告产物，不删除原始记录；未完成草稿询问保留或删除。

## 十二、家庭成员与临时照护（P1）

### J01 家庭成员列表

成员昵称、加入时间、角色、邀请状态、可访问宠物；操作邀请、改权限、看授权记录、撤权。

### J02 邀请成员页

选宠物、角色（可编辑/只读）、资料范围和有效期；提交前预览授权内容。

### J03 邀请分享页

生成链接/码并调用系统分享；显示有效期、复制、撤销。取消分享不撤销未过期邀请，成员列表仍可管理。

### J04 加入确认页

显示邀请人、宠物、角色、有效期；登录后接受/拒绝。过期/撤销分别展示状态。

### J05 权限编辑页

设置读取、编辑和邀请范围；修改前明确成员与影响宠物；可立即撤销。

### J06 成员访问记录

显示邀请、接受、修改权限、撤销和共享变动时间，不展示无关隐私。

### J07 临时照护清单编辑

选宠物和照护期限；勾选喂食、饮水、已确认用药说明、注意事项、主人填写的紧急联系人/兽医信息。药量按处方原文，不由 AI 生成。

### J08 临时照护清单预览

预览接收者可看到的字段；删减敏感资料、修改期限、确认范围。

### J09 分享与撤销状态

调用系统分享；可查看当前有效状态并撤销。失效链接不再显示资料。

### J10 撤销访问确认

显示成员/清单名称、权限和影响；确认后撤权并返回列表。

## 十三、“我的”、隐私和账号安全（P0/P1）

### K01 我的主页

入口：个人资料、宠物管理、家庭成员、提醒偏好、隐私与 AI、账号安全、资料请求、帮助反馈、协议和版本。

### K02 个人资料页与编辑页

展示/修改昵称、头像、邮箱、时区和提醒偏好。邮箱变更进验证流程；不采集性别、年龄、MBTI 等非必要字段。

### K03 提醒偏好页

进入通知设置、免打扰和分类开关；说明设置是全账号还是单宠物。

### K04 隐私中心

隐私政策、资料用途、AI 处理选项、公开内容、个人资料访问/更正/删除、注销和系统权限。

### K05 AI 与素材授权

分别设置个人记录检索、照片/视频语义搜索、包装识别和历史保存；关闭后提供手动替代路线。

### K06 系统权限状态

通知、照片/相机权限状态、用途和不授权影响；可打开系统设置。已有文字资料继续可用。

### K07 账号与安全

邮箱、修改密码、登录设备/会话、退出和注销。未实现的登录方式不显示入口。

### K08 修改邮箱页

验证当前账号，输入新邮箱并验证；只有验证成功后才切换邮箱，失败可重试。

### K09 修改密码页

当前密码、新密码、确认；成功后说明是否让其他设备退出；失败保留邮箱并清空密码。

### K10 协议页

隐私政策和用户协议可从注册、AI、社区入口打开；记录用户确认版本。更新时展示摘要和重新确认流程。

### K11 帮助与反馈

分类：账号、记录、提醒、AI、素材、协作、内容投诉。反馈可选附件；显示提交结果和编号。急重症问题不引导到普通客服排队。

### K12 退出确认

说明云端数据保留和本地未上传草稿处理；确认后回登录页。

### K13 资料复制/导出申请（P1）

选择宠物、记录和日期范围，提交复制/下载请求；显示处理中、完成、失败、链接过期和客服入口。

### K14 账号注销流程

分步说明个人资料、宠物、家庭权限、媒体、社区帖子、AI 会话和邀请的影响；先处理共享和发布内容，再验证身份、最终确认。

### K15 注销结果页

显示申请/完成/可撤回期状态与后续入口。撤回后回账号安全；删除后其他页面不得继续显示可访问状态。

## 十四、宠物圈子与社区（P2，需先具备运营治理）

### L01 社区内容流

“关注”“最新”两种排序；帖子显示作者、宠物、正文、时间、可见范围和审核状态。无关注内容时推荐关注或切换最新，不显示随机流。

### L02 话题/用户搜索

搜索昵称、宠物名或话题；支持清空、无结果和搜索历史清除。不得用私密档案做公开推荐。

### L03 用户公开主页

公开昵称、公开宠物卡片、帖子和关注状态；私密宠物不出现。屏蔽关系下双方内容不可见。

### L04 关注列表

关注中/关注者列表，支持关注、取消、屏蔽；解除屏蔽不自动恢复关注。

### L05 发布：选择内容

从相册选择照片/视频或允许公开的成长记录；显示素材公开状态，未选中的档案不自动带入。

### L06 发布：编辑内容

输入正文、话题、关联宠物、评论开关；可替换/删除素材和存草稿。

### L07 发布：可见范围与预览

公开、仅关注者、仅自己；完整预览后发布。AI 生成或编辑内容保留标识。

### L08 发布结果/审核状态

成功、审核中、失败、被拦截分别显示；可修改/删除草稿。审核中不得标为公开。

### L09 帖子详情

正文、素材、作者、范围、评论、点赞/收藏状态；本人可编辑/删除/改范围，其他用户可评论、点赞、收藏、举报、屏蔽。

### L10 评论页/编辑面板

评论、回复、删自己的评论、举报他人评论、屏蔽作者；失败保留草稿，显示审核状态。

### L11 互动通知

关注、点赞、评论、回复、帖子审核、举报结果。目标已删/无权时说明原因。

### L12 收藏列表

按宠物/话题筛选、取消收藏；源帖子删除或屏蔽时显示不可见状态。

### L13 举报页

明确举报帖子/评论/用户，选原因、说明、可选证据后提交；不向被举报者泄露举报人。

### L14 举报状态页

已提交、处理中、已处置、不予处置；提供补充信息/申诉（按平台流程）和社区规则入口。

### L15 屏蔽名单

确认屏蔽影响；列表可解除，解除后不自动恢复关注。

### L16 我的帖子管理

公开、审核中、仅自己、被限制分组；编辑、改范围、删除、看处理原因和申诉。

### L17 社区规则/账号限制

显示规则、限制范围、起止时间、处理理由和申诉入口。

**运营管理依赖（非普通 APP 页面）：** 公开社区至少需要管理台中的待审队列、举报列表/详情、处置、用户限制、申诉处理和操作记录。方案未定义管理台技术与运营岗位，准备完成前不开放社区发布。

## 十五、3D 形象与 AI 创作（P2，能力待确认）

### M01 3D 介绍与可用状态

说明当前能力、所需素材、处理用途和失败回退。若生成服务未选定，显示未开放；普通头像始终可用。

### M02 参考照片提交

仅在确定能力后开放；正面/侧面/背面拍摄指引，支持跳过、重拍、替换、撤销处理授权；不保证生成成功。

### M03 生成状态与取消

排队、处理中、成功、失败、取消；失败可重试或返回 2D 头像，不影响记录流程。

### M04 形象预览与采用

查看模型、设为首页展示、重新生成、删除；采用前预览，结果不合适可回头像。

### M05 形象隐私管理

查看/删除提交照片和模型，关闭生成能力。

### N01 创作类型选择

图文纪念卡、成长摘要或视频；未确认境内视频生成能力时视频不可选。

### N02 内容/素材选择

选宠物、时间范围、照片、记录和报告；显示将发给生成服务的资料。默认不加就医材料或家庭信息。

### N03 创作要求

选主题、长度、语言、语气；可选 AI 摘要或模板；显示标识说明。

### N04 生成确认

列出素材、生成类型、处理用途和标识；确认启动，取消返回内容选择。

### N05 生成状态

排队、处理中、取消、失败、重试；保留草稿和素材选择，避免重复提交。

### N06 结果编辑

查看文字/图片/视频，修改文字、替换素材、重做部分内容、保存草稿；AI 标识不得由应用移除。

### N07 分享确认

预览成品、范围、素材和标识后调用系统分享；取消回编辑，失败保留草稿。

## 十六、全局空状态、异常与恢复

| 状态 | 必须说明 | 用户可做 |
|---|---|---|
| 首次无数据 | 页面用途和最小下一步 | 添加宠物/首条记录/稍后 |
| 搜索无结果 | 当前词和筛选 | 清条件、改词、返回 |
| 断网 | 是否已保存、是否需重试 | 重试、存草稿、离开 |
| 登录过期 | 需重新验证 | 登录后回原页面 |
| 权限拒绝 | 用途和影响 | 替代操作、系统设置 |
| 上传失败 | 具体文件与状态 | 单项重试/移除，保留成功项 |
| AI 失败 | 未修改正式数据 | 重试、手动保存、返回 |
| AI 无资料依据 | 当前资料没有答案 | 添加记录/改问一般知识 |
| 对象已删/归档 | 对象当前状态 | 返回列表/有权限时恢复 |
| 审核中 | 内容尚未公开 | 看状态、撤回、编辑草稿 |
| 分享失效 | 已撤销/过期 | 返回或联系分享人 |
| 无权限 | 不泄露未授权内容 | 请求授权/返回 |
| 系统通知关闭 | 应用内待办仍可用 | 去设置/继续使用 |
| 索引处理中 | 可搜索功能当前状态 | 等待、取消、使用普通筛选 |
| 重复提交 | 已保存对象和时间 | 打开既有对象，不再重复创建 |

## 十七、关键端到端流程

1. **注册：** 欢迎 → 注册 → 邮箱验证 → 添加宠物（可跳过）→ 首页；邮件失败可重发，登录后恢复原目标。
2. **首页喂食：** 首页 → 快速记录 → 喂食表单 → 保存 → 详情；可继续记录或回首页。
3. **AI 转记录：** 输入原文 → 提取 → 字段核对 → 用户确认 → 详情；失败可手动保存，取消不写正式数据。
4. **建喂食计划：** 宠物/目标 → 食品/参考值 → 时段/复核 → 保存；公式说明页内展开，不增加强制步骤。
5. **提醒处理：** 首页/日历 → 详情 → 完成、延期、跳过或编辑；延期必须选新时间。
6. **照片入报告：** 相册 → 搜索/筛选 → 详情 → 加入报告；报告列表 → 设置 → 预览/编辑 → 来源核对 → 范围预览 → 系统分享。
7. **临时照护：** 我的/协作 → 选宠物和内容 → 预览 → 系统分享；已分享清单可查看或撤销。
8. **社区发帖（P2）：** 社区 → 选素材 → 编辑 → 可见范围/预览 → 发布/审核状态 → 帖子详情；举报、评论、屏蔽可从帖子详情到达。
9. **AI 创作（P2）：** 选类型 → 选内容 → 确认 → 状态 → 编辑结果 → 分享预览；失败保留草稿，标识保留。

## 十九、当前不设计交互入口的未定能力

以下项目在《项目初步设计.md》中属于待评估能力，缺少服务商、合作方或业务规则，不放入可点击的 APP 页面：

- **线上兽医问诊：** 需合规动物诊疗机构和执业兽医；未确定合作方不显示“立即问诊”。
- **商品交易/商城：** 未确定供应、支付、订单、售后和商家治理流程。
- **附近医院/服务点：** 未确定境内地图和地点数据服务。
- **智能设备接入：** 未确定型号、绑定、同步和异常恢复。
- **机器学习喂养优化：** 未确定数据规模、训练和审核方案。

能力确认后再补页面，不让用户进入无法完成的流程。

## 二十、页面交付完整性检查清单

- 页面有明确入口、返回目标和主导航归属。
- 当前宠物、账号身份、可见范围不会无提示丢失。
- 表单定义必填/选填、校验、取消和草稿恢复。
- 保存成功、失败、重复提交和网络恢复都有反馈。
- 空列表、无搜索结果、无权限、已删除、已归档分别有状态。
- 编辑/删除清楚指向具体对象，并解释关联提醒、素材、共享和报告的影响。
- 权限拒绝后仍有手动/只读替代操作。
- AI 字段有来源，低置信度待核对，所有写入需用户确认。
- 公开分享有范围选择和最终预览；素材默认私密。
- 社区发布、审核、举报、屏蔽、处置和申诉完整后才开放。
- P2 或依赖未确认的功能不会伪装成已上线入口。
