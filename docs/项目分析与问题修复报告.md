## 🔍 二、问题诊断

### 2.1 主要问题：web 目录无法在微信开发者工具中打开

#### **问题现象**
用户反馈：`D:\dev\Java\FaFa\web` 无法在微信开发者工具中打开调试

#### **根本原因分析**

经过详细检查，发现以下 4 个关键问题：

| 问题 | 文件 | 原因 | 影响 |
|------|------|------|------|
| ❌ AppID 未配置 | `project.config.json` | AppID 是占位符 `your-appid-here` | 无法导入项目 |
| ❌ API 地址错误 | `utils/config.js` | 使用示例域名 `https://api.example.com` | 网络请求失败 |
| ❌ 缺少 API 模块 | `utils/api.js` | 缺少 `photoApi`、`aiApi` 等导出 | 页面引用报错 |
| ❌ 响应码不匹配 | `utils/request.js` | 前端期望 `code: 0`，后端返回 `code: 200` | 数据解析失败 |
