## 🎯 架构亮点

### 1. DDD 设计原则
- **依赖倒置**: 领域层不依赖外层，Repository 接口在 domain 层定义
- **充血模型**: 业务逻辑封装在实体内（如 `Pet.updateWeight()`）
- **领域事件**: 解耦聚合之间的交互（如 `PetCreatedEvent`）
- **值对象**: 不可变对象，封装业务规则（如 `PetId`）

### 2. 职责分离
- **Java 服务**: 处理业务逻辑（用户、宠物、记录、提醒）
- **Python 服务**: 专注 AI 能力（对话、图片识别、向量搜索）
- **通过 RocketMQ 解耦**: 异步消息通信

### 3. 技术选型
- **轻量级鉴权**: Sa-Token（比 Spring Security 更简洁）
- **分布式缓存**: Redisson（支持分布式锁）
- **向量搜索**: Qdrant（高性能向量数据库）
- **AI 模型**: 通义千问 qwen3.7-flash（性价比高）
