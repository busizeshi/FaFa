# 用户信息

## 登录

可以选择微信一键登录，如果用户是首次进入，他可以选择微信一键登录，我们在微信小程序获取微信code，然后登录，如果是第一次使用，就直接注册返回。

之后用户再次进入，就最好不要再选择让用户登录，可以直接跳转到主界面。

## 用户信息管理

不需要记录用户的太多信息：只需要昵称，手机号，性别，年龄，头像，城市即可。

头像可以上传，但是在之后修改时，必须清理掉上一张头像(数据库和OSS都需要清理)，重新上传。

# 宠物信息

## 宠物创建

主要记录宠物的以下信息：
- 宠物名称
- 宠物类型(猫或者狗)
- 宠物年龄(但是数据库必须外推宠物出生日期，用于后续自动计算宠物年龄，年龄最好是几年几个月，可以让用户选择)
- 宠物性别
- 宠物照片(三张，一张作为宠物的头像，另外再需要一张宠物的正面照片，一张宠物的侧面照片)
- 宠物品种(比如哈士奇，英短等)：可以让用户进行选择或者输入，选择的话，我们根据猫狗类型，提供绝大多数品种
- 是否绝育
- 到家时间

宠物照片，我们需要再后端使用qwen3-vl-embedding模型，对宠物照片进行嵌入，向量数据库选择使用Qdrant。

**可以创建多只宠物，必须注意我们之后会有会员功能，普通用户最多只能创建两只宠物，会员用户可以创建任意数量的宠物。**

**宠物创建完成后，必须根据名称给用户的tags添加一个宠物的标签，标签名称就是宠物的名称。方便后期进行检索**

## 宠物编辑

以上信息都允许编辑，宠物照片如果更新了，必须清理掉之前的OSS数据以及Qdrant的向量数据，重新向量化和存储。

编辑允许调整多只宠物的排序

## 查询

必须包含列表查询，和单一宠物的详情查询

# 宠物素材上传与检索(图片、视频)

## 上传

素材的上传必须可以让用户自己选择tag来打上标签，或者新建一个tag来打上标签(只需要输入文字即可)。

上传的素材可以选择tags来打上标签，然后加上用户自己的文字描述，注意：用户可能是按批上传的，所以tags和文字描述也必须是一批一个。这一批可能只有一个素材，也可能是有多个素材。

上传后，如果用户有多个宠物，需要根据用户在创建宠物的时候上传的三张图片的向量，分别和用户上传的素材进行向量相似度匹配，如果向量相似度达到阈值，则认为该素材是该宠物的素材，用该宠物的名称给该素材打上tags。

## 检索

我们会给用户提供一个检索功能，用户可以直接使用一段文字，然后配合llm，来进行检索，也可以叠加其他查询条件，比如宠物名称，tags，以及时间范围。

# 记录

类似一个打卡记录，不过我们有自己的打卡规则。

## 主要设计为三类：

| 类别 | 定义 | 例子 | 形态 |
|------|------|------|------|
| **状态观察** | 它表现如何 | 食欲、精神、饮水程度、便便质量 | 主观量表，一天一格，upsert |
| **照护动作** | 我做了什么 | 喂食、换水、给药、驱虫 | 事件流，几点几分发生 |
| **周期测量** | 精确数值 | 体重、克数、毫升 | 独立流程 + 温和提醒，**绝不进每日打卡** |

我们希望：**任何每日记录 ≤2 次点击完成。**

按可观察性 / 临床价值 / 记录成本 / 纵向价值四把尺子评估：

## 记录项

| 维度 | 形态 | 选项 | 核心价值 |
|------|------|------|---------|
| 食欲 | 量表 | 很好 / 正常 / 下降 / 拒食 | 几乎所有疾病的共同首发信号；猫拒食 >2 天有肝脂沉积风险 |
| 精神/活动 | 量表 | 活跃 / 正常 / 低迷 | 猫生病天性躲藏不动；措辞必须是「比平时」而非绝对档位 |
| 饮水程度 | 量表 | 正常 / 偏多 / 偏少 / **没注意** | 猫多饮多尿 = 肾病/糖尿病/甲亢三大最早期信号（10 岁以上猫 30%+ 有慢性肾病）；必须有「没注意」逃生口 |
| 排便 | 量表 | 正常 / 偏软 / 腹泻 / 便秘 / 没看到 | 特权数据（每天铲屎/捡屎一目了然）；现有 excretion_record 结构可平移 |
| 呕吐 | 症状开关 | 无（默认）/ 一次 / 多次 | 拒食+呕吐 = 急症组合信号 |
| 排尿 | 症状开关 | 正常 / 异常 / 没看到 | 公猫排尿困难是按小时计的急症（尿道阻塞）；全产品唯一可能「救命」的场景 |

小程序在记录也必须有：同昨日按钮，用户可以看到昨天的记录，然后点击按钮后，就可以直接使用昨天的记录作为今天的记录。

## 物种差异（配置，非两套代码）

| | 猫默认面 | 狗默认面 |
|--|---------|---------|
| 维度 | 食欲、精神、饮水（加权提示多饮多尿）、呕吐、排便、排尿 | 食欲、精神、排便、饮水、呕吐（排尿降权） |
| 依据 | 猫肾病/糖尿病早期信号靠多饮多尿捕捉；猫砂盆排尿行为完全可见 | 狗捡屎是每日特权数据；排尿观察难 |
