# FaFa 宠物生活助手 - 后端开发计划

> **项目说明**：基于 Spring Boot 3.x (Java) + FastAPI (Python) 的双服务架构  
> **开发周期**：预计 8-10 周  
> **开发模式**：迭代开发，每个阶段可独立运行和测试

---

## 一、整体开发策略

### 1.1 开发原则

1. **MVP 优先**：先实现核心功能，确保可用
2. **模块解耦**：Java 和 Python 服务独立开发，通过 API 和 MQ 通信
3. **数据驱动**：先建立数据基础，再添加 AI 能力
4. **迭代验证**：每个阶段完成后进行集成测试

### 1.2 技术栈确认

**Java 服务 (端口: 8080)**
- Spring Boot 3.2+
- MyBatis-Plus 3.5+
- Sa-Token 1.37+
- MySQL 8.0+
- Redis 7.0+
- RocketMQ 5.x
- MinIO / 阿里云 OSS

**Python 服务 (端口: 8000)**
- FastAPI 0.110+
- LangChain 0.1+
- LangGraph 0.0.20+
- Qdrant 1.7+
- DashScope SDK (通义千问)
- RocketMQ Client

  from langgraph.graph import StateGraph, END

## 十三、风险与应对

### 13.1 技术风险

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| AI 接口不稳定 | 照片分析、报告生成失败 | 重试机制 + 降级方案 |
| Qdrant 性能问题 | 照片搜索慢 | 优化索引 + 限制搜索范围 |
| MQ 消息堆积 | 异步任务延迟 | 增加消费者 + 监控告警 |
| 数据库性能瓶颈 | 接口响应慢 | 索引优化 + 读写分离 |

### 13.2 进度风险

| 风险 | 影响 | 应对措施 |
|------|------|---------|
| AI Agent 开发复杂 | 延期1周 | 简化工具数量，先实现核心工具 |
| 微信小程序对接延迟 | 无法测试推送 | 使用模拟数据测试 |
| 第三方服务不稳定 | 开发受阻 | 准备备用方案（如本地 MinIO） |
