## 📝 特性说明

### 1. **字符集和排序规则**
- 所有表使用 `utf8mb4` 字符集
- 排序规则：`utf8mb4_unicode_ci`
- 支持 emoji 和特殊字符 ✅

### 2. **时间字段**
- `created_at`：自动记录创建时间
- `updated_at`：自动更新修改时间
- 使用 `DATETIME` 类型，支持时区 `+08:00`

### 3. **索引设计**
- 所有外键字段都有索引（如 user_id, pet_id）
- 时间范围查询字段有联合索引（如 pet_id + record_date）
- 唯一性约束（如 openid, pet_id + record_date）
- AI 相关字段索引（如 embedding_id）

### 4. **JSON 字段**
- tags：用户标签和 AI 标签
- sections：报告分段内容
- agent_state：AI Agent 状态
- details：操作详情
- 支持灵活的数据结构 ✅

### 5. **软删除支持**
- 部分表支持状态字段（如 status: 0-禁用, 1-正常）
- 可以在不删除数据的情况下隐藏记录
