## 📝 需要您填写的配置

在启动服务前，请在以下文件中填入实际值：

### `.env` 文件
```ini
# 必须填写
DASHSCOPE_API_KEY=sk-xxxxxxxx  # 通义千问 API Key

# 微信小程序（如需登录功能）
WECHAT_APPID=wx1234567890abcdef
WECHAT_SECRET=abcdef1234567890
```

### `fafa-python/.env` 文件
```ini
# 必须填写
DASHSCOPE_API_KEY=sk-xxxxxxxx  # 通义千问 API Key
```

### 其他配置
如果使用本地 Docker 中间件，其他配置项保持默认即可。

## 🚀 快速配置步骤

```powershell
# 1. 编辑项目根目录 .env
notepad .env
# 填入 DASHSCOPE_API_KEY

# 2. 编辑 Python 服务 .env
notepad fafa-python\.env
# 填入 DASHSCOPE_API_KEY

# 3. 运行配置检查脚本
.\check-config.ps1

# 4. 如果检查通过，启动中间件
docker-compose up -d

# 5. 启动服务
# Java: cd fafa-java; mvn spring-boot:run
# Python: cd fafa-python; uvicorn app.main:app --reload
```
