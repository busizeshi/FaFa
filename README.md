# FaFa AI 宠物生活助手 - UI设计系统

## 项目概述
完整的微信小程序UI设计原型，包含10个页面的可交互HTML+CSS实现。

## 设计风格
- **色彩系统**：温暖大地色系，奶油色背景 #F7F4EF，赤陶橙主题色 #C4612F
- **形态语言**：圆润友好，12-16px圆角卡片，999px完全圆角按钮
- **交互细节**：按钮按下态Y偏移+2px，卡片轻阴影，所有头像圆形

## 技术实现

### 色彩系统
```css
--background: #F7F4EF;      /* 页面背景 */
--surface: #FBF9F5;         /* 卡片表面 */
--white: #FFFFFF;           /* 纯白 */
--primary: #C4612F;         /* 主题色 */
--primary-hover: #A94E22;   /* 主题色悬停 */
--primary-tint: #F2E3D6;    /* 主题色浅色 */
--ink: #1F2421;             /* 主要文字 */
--muted: #5C635D;           /* 次要文字 */
--border: #E7E1D7;          /* 边框 */
```

### 间距系统
- 页面左右边距：16px
- 卡片内边距：16px
- 卡片间距：12px
- 表单字段间距：16px

### 圆角规范
- 小圆角（输入框）：8px
- 中圆角（卡片）：12px
- 大圆角（弹窗）：16px
- 完全圆角（按钮/标签）：999px

### 交互细节
- 按钮按下态：`transform: translateY(2px)`
- 卡片阴影：`0 2px 8px rgba(0, 0, 0, 0.04)`
- 悬停阴影：`0 4px 12px rgba(0, 0, 0, 0.08)`
- 弹窗动画：从底部滑入 `@keyframes slideUp`
- AI按钮动画：脉动效果 `@keyframes pulse`

### Canvas图表实现
体重趋势图使用Canvas 2D绘制：
- 网格线
- 渐变填充区域
- 折线路径
- 数据点（白色填充+橙色描边）
