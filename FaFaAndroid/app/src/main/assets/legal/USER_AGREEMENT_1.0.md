# FaFa 用户协议

版本：1.0（内置文本，与服务端 `legalVersions.USER_AGREEMENT` 对齐）

## 1. 协议的接受与变更

欢迎使用 FaFa（下称"本应用"）。在你勾选同意并完成注册前，请务必审慎阅读本协议全部内容，特别是免除或限制责任、争议解决等条款。你勾选"我已阅读并同意"即视为你已理解并接受本协议全部内容。

我们可能随产品能力演进更新本协议；协议版本变化时，本应用会再次弹出同意提示，你在新版本文本上重新同意后方可继续使用对应功能。你可以随时在本应用内查看当前版本的协议文本。

## 2. 服务内容

本应用为家庭宠物照护辅助工具，提供喂食、饮水、排泄、活动、体重与健康事件的记录、提醒、多人协作、资料整理，以及基于已授权数据的整理与解释能力。

本应用不提供医疗诊断、处方或治疗建议。所有用药与治疗方案请以执业兽医的原医嘱为准；紧急情况请立即联系兽医或宠物急诊机构。

## 3. 账号与安全

- 你需使用有效的电子邮箱注册账号，并妥善保管账号凭据。
- 注册后需完成邮箱验证方可激活账号；未验证的账号无法登录。
- 你可以通过"找回密码"重设密码；重设成功后，该账号在所有设备上的登录会话将被撤销。
- 你可以在多设备管理中查看与下线你的登录会话。
- 若发现账号被停用且认为有误，可通过应用内提供的客服邮箱提交申诉。

## 4. 用户行为规范

你承诺不利用本应用从事任何违反法律法规或侵犯他人合法权益的行为，包括但不限于：发布违法信息、侵害他人隐私、上传你无权使用的他人作品，以及干扰或破坏本应用及相关服务的正常运行。

## 5. 家庭协作与授权

你可以创建家庭并邀请其他成员共同照护宠物。你授予其他成员的查看与操作权限范围由你自行选择；请谨慎授权，并在成员退出照护后及时撤销其权限。

## 6. 知识产权

本应用的软件、界面设计、图标与文案等内容的知识产权归本应用运营方所有。你在本应用中创建的宠物资料、照护记录与照片等内容的权利归属及使用范围，以《隐私政策》相关约定为准。

## 7. 责任限制

本应用以"现状"提供服务。因不可抗力、网络故障、设备故障或非本应用原因导致的服务中断或数据损失，本应用在法律允许的最大范围内不承担责任。本应用对记录与提醒仅提供辅助管理能力，不对宠物的健康结果作出承诺。
